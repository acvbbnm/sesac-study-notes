1\. 결측치 처리 (Missing Values)

- **제거(Deletion):** 결측 행/열 삭제. 간단하지만 정보 손실이 큼

- **대체(Imputation):** 평균·중앙값·최빈값 등으로 채움. 가장 보편적

import numpy as np

from sklearn.impute import SimpleImputer

\# ① 논리적 결측치(0)를 진짜 결측치(NaN)로

cols = \["Glucose","BloodPressure","SkinThickness","Insulin","BMI"\]

df\[cols\] = df\[cols\].replace(0, np.nan)

\# ② 평균으로 대체

imputer = SimpleImputer(strategy="mean") \# median, most_frequent, constant

df\[cols\] = imputer.fit_transform(df\[cols\])

3\. 범주형 인코딩 (Encoding)

모델은 문자를 못 읽으므로 범주(문자)를 숫자로 바꿉니다. 대표적으로 **원-핫 인코딩**: 각 범주를 새 열로 만들어 해당하면 1, 아니면 0.

\# 연속형 Age → 구간(범주)으로: pd.cut

bins = \[20, 30, 40, 50, 60, 70, 80\]

labels = \['20s','30s','40s','50s','60s','70s'\]

df\['Age_groups'\] = pd.cut(df\['Age'\], bins=bins, labels=labels,

right=False) \# 이상~미만 (왼쪽 포함)

\# 원-핫 인코딩: pd.get_dummies

X = pd.get_dummies(df, columns=\['Age_groups'\], dtype=int) \# 0/1 반환

4\. 이상치 처리 (Outliers)

다른 값들과 크게 동떨어진 값. 통계를 왜곡하고 모델 성능을 떨어뜨립니다. 확인·처리 방법 세 가지:

- **박스 플롯:** 중앙값·Q1·Q3·수염을 시각화. 수염 밖 점이 이상치

- **IQR:** 사분위 기반, 박스플롯의 논리적 근거 (가장 널리 씀)

- **Z-Score:** 정규분포 가정, 평균에서 표준편차의 몇 배인지. ±3 벗어나면 이상치

IQR 방식 공식

| **항목**    | **계산**                      |
|-------------|-------------------------------|
| IQR         | Q3 - Q1 (중간 50% 범위)       |
| 하한(lower) | Q1 - 1.5 × IQR                |
| 상한(upper) | Q3 + 1.5 × IQR                |
| 이상치      | 하한 미만 또는 상한 초과인 값 |

\# LAB: IQR로 BloodPressure 이상치 제거

Q1 = df\["BloodPressure"\].quantile(0.25)

Q3 = df\["BloodPressure"\].quantile(0.75)

IQR = Q3 - Q1

lower = Q1 - 1.5 \* IQR

upper = Q3 + 1.5 \* IQR

\# 경계 안(정상치)만 남기기

clean = df\[(df\["BloodPressure"\] \>= lower) & (df\["BloodPressure"\] \<= upper)\]

print(df.shape, "→", clean.shape) \# 행 수 감소 확인

5\. 데이터 분포 변환 (Transformation)

선형 회귀 같은 모델은 데이터가 **정규분포에 가까울 때** 성능이 좋습니다. 한쪽으로 치우친(왜도 큰) 분포를 종 모양에 가깝게 펴 줍니다.

| **방법** | **특징** | **제약** |
|----|----|----|
| **로그 변환** | 가장 대중적. 큰 값을 강하게 압축, 긴 오른쪽 꼬리 완화 | 0·음수 불가 → log(x+1) 사용 |
| **제곱근 변환** | 로그보다 완만한 압축 | 0도 처리 가능 |
| **박스-콕스** | λ를 자동으로 찾아 최적 변환 | **양수(x\>0)만** 가능 |
| **여-존슨** | 박스-콕스 보완 최신 기법 | **음수·0 포함**도 가능 (실무 유용) |

import numpy as np

\# 로그 변환 (0이 있어 log1p = log(x+1) 사용)

df\["Insulin_log"\] = np.log1p(df\["Insulin"\])
