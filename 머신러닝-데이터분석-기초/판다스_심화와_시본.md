**판다스 심화와 시본**

1\. 데이터 정렬 (sort_values)

특정 열을 기준으로 행을 재배열합니다. 기본은 오름차순, **ascending=False** 로 내림차순.

titanic.sort_values(by="Age").head() \# 나이 오름차순

\# 여러 기준: Pclass 먼저, 같으면 Age 로 (둘 다 내림차순)

titanic.sort_values(by=\["Pclass", "Age"\], ascending=False).head()

2\. 데이터 재구조화 — Long ↔ Wide

같은 데이터도 모양을 바꿔 다르게 볼 수 있습니다. 두 형태를 이해하는 것이 핵심입니다.

| **형태** | **특징** | **예** |
|----|----|----|
| **Long (긴 형태)** | 한 행 = 한 관측치. 항목이 세로로 쌓임 | date·location·parameter·value 열로 한 줄씩 |
| **Wide (넓은 형태)** | 한 범주 = 한 열. 항목이 가로로 펼쳐짐 | 측정소별로 열을 나눠 시간마다 값이 나란히 |

2.1 pivot() — Long → Wide

한 열의 값들을 **열 이름으로 펼쳐** 표를 넓게 만듭니다.

\# 측정소(location)를 열로, value를 값으로 → 시간별 나란히 정렬

no2.pivot(columns="location", values="value")

\# 여러 열이 생기므로 시계열 멀티라인 그래프도 한 번에

no2.pivot(columns="location", values="value").plot()

plt.show()

2.2 pivot_table() — 집계까지 함께

pivot()과 비슷하지만 **중복 데이터를 자동으로 요약(집계)**합니다. 같은 시간·장소 값이 2개 이상이면 pivot()은 오류가 나지만 pivot_table()은 aggfunc로 처리합니다.

air_quality.pivot_table(

index="location", \# 행이 될 기준

columns="parameter", \# 열이 될 기준 (no2, pm25 …)

values="value", \# 채울 값

aggfunc="mean", \# 집계 방식: 평균

margins=True, \# 총합/총평균 행·열 추가

margins_name="총평균" \# 기본 "All" 대신 이름 변경

)

2.3 melt() — Wide → Long

넓은 표를 다시 세로로 녹입니다(melt=녹이다). 여러 열을 **변수(variable)와 값(value) 두 열로** 접습니다.

\# 먼저 인덱스를 일반 열로 꺼내기

no2_reset = no2_pivoted.reset_index()

no2_long = no2_reset.melt(

id_vars="date.utc", \# 고정할 기준 열

value_vars=\["BETR801","FR04014","London Westminster"\], \# 녹일 열들

var_name="id_location", \# 열 이름들이 모일 컬럼명 (기본 variable)

value_name="NO2" \# 값들이 모일 컬럼명 (기본 value)

)

3\. 그룹별 처리 (groupby)

특정 열의 값이 같은 행끼리 **묶어서(그룹)** 한꺼번에 처리합니다. '분할 → 적용 → 결합'의 흐름입니다.

\# 시간순 정렬 후, 측정소별로 묶어 각 그룹의 상위 2개 행만

no2.sort_index().groupby(\["location"\]).head(2)

\# 그룹별 평균 같은 집계도 가능

\# titanic.groupby("Pclass")\["Age"\].mean()

4\. 여러 테이블 결합 (concat)

구조가 비슷한 두 테이블을 이어붙일 때 **concat()** 을 씁니다. **axis=0** 은 위아래(세로) 결합입니다.

air_quality = pd.concat(\[air_quality_pm25, air_quality_no2\], axis=0)

\# 행 번호가 뒤섞이면 → 0부터 다시 매기기

air_quality = pd.concat(\[...\], axis=0, ignore_index=True)

\# 어느 테이블 출신인지 표시 → keys

combined = pd.concat(\[pm25, no2\], keys=\["PM25", "NO2"\])

combined.loc\["PM25"\] \# 특정 그룹만 조회

5\. 시본(Seaborn) 시각화

Matplotlib 기반이지만 **더 예쁜 디자인과 통계 그래프**를 쉽게 그리는 라이브러리. 판다스 DataFrame과 완벽히 연동됩니다. 관례상 **import seaborn as sns**.

import seaborn as sns

import matplotlib.pyplot as plt

flights = sns.load_dataset("flights") \# 내장 예제 데이터

\# 공통 패턴: sns.그래프종류(data=df, x="열", y="열")

sns.barplot(data=flights, x="year", y="passengers")

plt.show()

5.1 그래프 종류별 쓰임

| **그래프** | **무엇을 보여주나** | **언제 쓰나** |
|----|----|----|
| **barplot** | 범주별 **평균값**(+오차선) | 그룹 간 대표값 비교 |
| **boxplot** | 5대 통계(중앙값·사분위·최대/최소)와 이상치 | 데이터 **분포·이상치** 한눈에 |
| **violinplot** | 박스플롯 + 밀도(KDE) 곡선 | 분포의 **모양·밀집** 구간까지 |
| **swarmplot** | 겹치지 않게 흩뿌린 **실제 점 하나하나** | 개별 관측치 분포 확인 (박스와 겹쳐 씀) |
| **lineplot** | 추세선(평균) + 95% 신뢰구간 음영 | 시간에 따른 **추세·변동성** |
| **histplot** | 구간별 빈도 막대(+KDE 곡선) | 한 변수의 **분포·치우침** |

자주 쓰는 꾸미기

plt.figure(figsize=(12, 5)) \# 도화지 크기

sns.boxplot(data=flights, x="year", y="passengers")

plt.title("연간 승객 분포", fontsize=14) \# 제목

plt.xlabel("연도"); plt.ylabel("승객수") \# 축 라벨

plt.show()

\# 박스플롯 위에 실제 점(swarm) 겹쳐 그리기

sns.boxplot(data=flights, x="year", y="passengers", color="white")

sns.swarmplot(data=flights, x="year", y="passengers", size=5)

\# 히스토그램 + 밀도곡선

sns.histplot(data=flights, x="passengers", kde=True, bins=20)
