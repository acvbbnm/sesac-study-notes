1\. 판다스(Pandas) 개요

파이썬에서 **데이터 조작·분석**을 위해 쓰는 대표 오픈소스 라이브러리. 엑셀·데이터베이스의 **표(Table)** 형태처럼 행과 열로 이루어진 정형 데이터를 다루는 데 특화돼 있습니다.

핵심 자료구조 2가지

| **자료구조** | **차원** | **설명** |
|----|----|----|
| **Series (시리즈)** | 1차원 | 값 + 인덱스(index)로 구성된 한 줄짜리 배열. DataFrame의 **한 열**이 곧 Series |
| **DataFrame (데이터프레임)** | 2차원 | 행(Row)과 열(Column)로 된 **표**. 가장 널리 쓰임. 여러 Series가 모인 것 |

판다스를 쓰는 이유

- **다양한 파일 지원:** CSV·Excel·SQL·JSON 등을 쉽게 불러오고 저장

- **데이터 정제:** 결측치(빈 값)·중복 데이터를 간단히 찾아 제거·대체

- **강력한 조작:** 필터링·정렬·그룹화·병합

- **시계열 처리:** 날짜·시간 데이터(주가·로그 등)에 강함

- **연동성:** Matplotlib·Seaborn(시각화), Scikit-Learn(머신러닝)과 원활히 연결

2\. DataFrame · Series 만들기

import pandas as pd

\# 딕셔너리로 DataFrame 생성 (키=열이름, 값=열데이터 리스트)

data = {

"name": \["김철수", "이영희", "박민수"\],

"age": \[25, 30, 22\],

"city": \["서울", "부산", "인천"\]

}

df = pd.DataFrame(data)

df\["age"\] \# 한 열 선택 → Series 반환

\# Series 직접 생성

ages = pd.Series(\[22, 33, 44\], name="Age")

3\. 데이터 파악하기 (탐색)

데이터를 불러온 직후 가장 먼저 하는 일 — 전체 모습과 상태를 빠르게 확인합니다.

| **메서드 / 속성** | **기능** |
|----|----|
| **head(n)** / **tail(n)** | 앞 / 뒤 n행 미리보기 (기본 5행) |
| **shape** | (행 개수, 열 개수) 반환 — 괄호 없는 속성 |
| **dtypes** | 각 열의 데이터 타입 확인 |
| **info()** | 종합 정보: 행 개수, 열별 결측치 아닌 개수(Non-Null), 타입, 메모리 |
| **describe()** | 수치형 열의 통계: count·mean·std·min·25/50/75%·max |
| **describe(include='all')** | 문자열 포함 전체: 고윳값(unique)·최빈값(top)·빈도(freq)까지 |

titanic = pd.read_csv("titanic.csv") \# CSV 불러오기

titanic.head(8) \# 앞 8행

titanic.shape \# (891, 12) → 891행 12열

titanic.info() \# 결측치·타입·메모리 종합

titanic.describe() \# 수치형 열 요약 통계

<p><strong>info()</strong> 는 '데이터가 온전한가(결측치·타입)'를 점검할 때, <strong>describe()</strong> 는 '값들의 분포·평균은 어떤가'를 볼 때 씁니다. 50%는 중앙값(median)과 같습니다.</p></td>

4\. 데이터 선택 · 필터링

4.1 열(Column) 선택

titanic\["Age"\] \# 한 열 → Series (1차원)

titanic\[\["Age", "Sex"\]\] \# 여러 열 → DataFrame (2차원, 대괄호 2개!)

4.2 행(Row) 필터링 — 조건

\# 나이가 35 초과인 행만

above_35 = titanic\[titanic\["Age"\] \> 35\]

\# titanic\["Age"\] \> 35 자체는 True/False Series (조건 마스크)

\# 여러 값 중 하나 → isin()

titanic\[titanic\["Pclass"\].isin(\[2, 3\])\]

\# 같은 의미를 \| (또는) 로

titanic\[(titanic\["Pclass"\] == 2) \| (titanic\["Pclass"\] == 3)\]

\# 결측치가 아닌(값이 있는) 행만 → notna()

titanic\[titanic\["Age"\].notna()\]

<p>판다스 필터의 원리는 <strong>True/False로 이루어진 조건 마스크</strong>를 대괄호 안에 넣어 True인 행만 남기는 것입니다.</p>
<p>여러 조건은 파이썬의 and/or가 아니라 <strong>&amp; (그리고), | (또는)</strong> 를 쓰고, <strong>각 조건을 소괄호( )로 감싸야</strong> 합니다. 우선순위 때문에 괄호를 빼면 오류가 납니다.</p></td>

4.3 행 + 열 동시 선택 — loc vs iloc

|  | **loc** | **iloc** |
|----|----|----|
| 기준 | **이름(라벨)** 기반 | **위치(번호)** 기반 |
| 문법 | df.loc\[행이름, 열이름\] | df.iloc\[행번호, 열번호\] |
| 예시 | titanic.loc\[titanic\["Age"\]\>35, "Name"\] | titanic.iloc\[9:25, 2:5\] |
| 범위 끝 | 끝 라벨 **포함** | 끝 번호 **미포함** (파이썬 슬라이싱과 동일) |

\# 조건 + 특정 열: 35세 초과 승객의 이름만

titanic.loc\[titanic\["Age"\] \> 35, "Name"\]

\# 위치로: 10~24행, 3~5열

titanic.iloc\[9:25, 2:5\]

\# 값 할당도 가능

titanic.iloc\[0:3, 3\] = "anonymous"

<td><p><strong>💡 loc / iloc — 이 단원 최대 함정</strong></p>
<p><strong>loc = label(라벨)</strong>, <strong>iloc = integer(정수 위치)</strong> 로 외우면 쉽습니다. loc는 조건식·컬럼 이름과 함께 쓰기 좋고, iloc는 '몇 번째'로 접근할 때 씁니다.</p>
<p><strong>끝 범위 처리가 다릅니다:</strong> loc[2:5]는 라벨 5까지 포함, iloc[2:5]는 위치 5 직전(2·3·4)까지입니다. 시험에 자주 나오는 차이입니다.</p></td>

5\. 그래프 그리기 (시각화)

DataFrame·Series에 내장된 **.plot()** 메서드로 간단히 그래프를 그립니다. 내부적으로 **Matplotlib** 을 사용합니다.

import pandas as pd

import matplotlib.pyplot as plt

data = {"날짜": \["월","화","수","목","금"\],

"매출": \[100,120,115,130,150\],

"지출": \[70,80,75,90,85\]}

df = pd.DataFrame(data)

\# "날짜"를 인덱스로 → x축에 날짜 표시 (안 하면 0,1,2… 가 x축)

df.set_index("날짜", inplace=True) \# inplace=True: 원본에 바로 반영

df.plot() \# 꺾은선 (기본)

plt.show()

df.plot(kind="bar") \# 막대

plt.title("요일별 매출·지출")

plt.show()

kind 파라미터 — 그래프 종류

| **kind** | **그래프**      | **kind** | **그래프**        |
|----------|-----------------|----------|-------------------|
| line     | 꺾은선 (기본값) | hist     | 히스토그램        |
| bar      | 수직 막대       | box      | 박스 플롯         |
| barh     | 수평 막대       | pie      | 원 그래프         |
| area     | 영역 그래프     | scatter  | 산점도(x, y 지정) |

.plot() 주요 파라미터

- **x, y:** 축에 쓸 컬럼 이름

- **figsize:** 그래프 크기 (인치 단위, 예: (8,5))

- **title / grid:** 제목 / 배경 격자 표시 여부

- **color / alpha:** 색상 / 투명도(0~1)

- **subplots=True:** 각 열을 별도 그래프로 분리

df.plot(y=\["매출","지출"\], figsize=(8,5), title="요일별 매출과 지출",

grid=True, color=\["red","green"\], alpha=0.7)

plt.show()

\# 산점도: 두 변수의 관계 비교

air_quality.plot(kind="scatter", x="station_london",
