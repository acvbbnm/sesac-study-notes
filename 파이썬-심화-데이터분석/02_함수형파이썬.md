1\. 클로저 (Closure)

중첩 함수가 바깥 함수의 지역 변수를 참조하면, **바깥 함수가 끝난 뒤에도 그 변수에 계속 접근**할 수 있습니다. 데코레이터의 기반이 되는 개념입니다.

1.1 클로저 성립 3조건

1.  중첩 함수: inner가 outer 내부에 정의

2.  바깥 변수 참조: inner가 outer의 변수를 읽음

3.  내부 함수 반환: outer가 inner 객체를 반환 (괄호 없음)

셋 중 하나라도 빠지면 평범한 함수입니다.

def outer():

message = "안녕하세요"

def inner():

return message \# 바깥 변수 참조

return inner \# 괄호 없이 함수 자체 반환

hello = outer() \# outer는 여기서 종료

print(hello()) \# 안녕하세요 (message에 여전히 접근)

1.2 nonlocal — 바깥 변수 재할당

중첩 함수에서 바깥 변수에 **다시 대입**하려면 nonlocal이 필요합니다. 선언하지 않으면 대입 대상이 지역 변수로 판정되어 **UnboundLocalError**가 납니다.

def make_counter():

count = 0

def counter():

nonlocal count \# 없으면 UnboundLocalError

count += 1

return count

return counter

c1 = make_counter(); c2 = make_counter()

print(c1(), c1(), c1()) \# 1 2 3

print(c2()) \# 1 (c1·c2는 각자 독립된 count)

<td><p><strong>💡 nonlocal이 필요할 때 / 아닐 때</strong></p>
<p><strong>재할당(=, +=)</strong>에는 nonlocal 필요. 반면 리스트 <strong>.append()</strong> 같은 '내부 변경'은 재할당이 아니라 nonlocal 없이도 됩니다. 각 make_counter() 호출은 독립된 count를 가진 별개 클로저를 만듭니다.</p></td>

1.3 팩토리 함수와 람다 클로저

def make_multiplier(n):

return lambda value: n \* value \# n을 포획 (람다도 클로저)

double = make_multiplier(2) \# n=2 기억

triple = make_multiplier(3) \# n=3 기억

print(double(10), triple(10)) \# 20 30

같은 본체지만 각자 다른 n을 저장합니다. 람다도 자신을 둘러싼 스코프의 변수를 참조하면 클로저가 됩니다.

1.4 late-binding 루프 함정 (중요)

funcs = \[lambda: i for i in range(3)\]

print(\[f() for f in funcs\]) \# \[2, 2, 2\] ← 0,1,2 아님!

\# 고침: 정의 시점의 i를 기본값에 고정

funcs = \[lambda i=i: i for i in range(3)\]

print(\[f() for f in funcs\]) \# \[0, 1, 2\]

2\. 데코레이터 (Decorator)

로그·시간 측정 같은 **부가 기능을 원본 함수 밖에서 한 번만 정의해 적용**하는 기법. 원본 동작은 그대로 두고 공통 기능을 분리합니다.

2.1 기본 구조 — 감싸기

def add_log(func):

def wrapper():

print("\[로그\] 시작") \# before

func() \# 원본 실행 (본문 무수정)

print("\[로그\] 끝") \# after

return wrapper \# 감싼 새 함수를 반환

@add_log \# = say_hello = add_log(say_hello)

def say_hello():

print("안녕하세요!")

say_hello() \# 로그 시작 / 안녕하세요! / 로그 끝

<td><p><strong>💡 @데코 = 재대입 축약</strong></p>
<p><strong>@add_log</strong> 는 <strong>say_hello = add_log(say_hello)</strong>와 완전히 같은 축약 문법입니다. add_log가 반환한 wrapper가 say_hello 이름에 다시 대입되어, 이후 say_hello()는 wrapper를 실행합니다.</p></td>

2.2 인자·반환값 전달 + @wraps

from functools import wraps

def add_log(func):

@wraps(func) \# 원본 이름·독스트링 보존

def wrapper(\*args, \*\*kwargs): \# 임의 인자 받기

result = func(\*args, \*\*kwargs) \# 그대로 전달 → 결과 저장

return result \# 반환값 보존

return wrapper

| **wrapper 요소** | **없으면 생기는 문제** |
|----|----|
| \*args, \*\*kwargs | 인자 있는 함수에서 TypeError |
| result = func(\*args, \*\*kwargs) | 원본 실행 결과를 못 잡음 |
| return result | 호출 결과가 None |
| @wraps(func) | \_\_name\_\_이 'wrapper'로 덮이고 독스트링이 사라짐 |

<p>데코레이터를 적용하면 함수 이름이 wrapper로 바뀌어 <strong>__name__이 'wrapper'</strong>로, 독스트링은 None이 됩니다. <strong>@wraps(func)</strong> 한 줄이 원본의 이름·독스트링을 복사해 디버깅·문서화를 정상으로 유지합니다.</p></td>

2.3 실전 데코레이터 — @timed, retry

\# 실행 시간 측정

import time

def timed(func):

@wraps(func)

def wrapper(\*args, \*\*kwargs):

t0 = time.perf_counter()

result = func(\*args, \*\*kwargs)

print(f"\[{func.\_\_name\_\_}\] {time.perf_counter()-t0:.6f}초")

return result

return wrapper

\# 인자 받는 데코레이터 = 3중 중첩 (retry·decorator·wrapper)

def retry(times):

def decorator(func):

@wraps(func)

def wrapper(\*args, \*\*kwargs):

for i in range(1, times+1):

try: return func(\*args, \*\*kwargs)

except ConnectionError:

if i == times: raise \# 마지막이면 예외 전파

return wrapper

return wrapper

return decorator

<tr>
<td><p><strong>💡 인자를 받는 데코레이터는 3겹</strong></p>
<p><strong>retry(설정) → decorator(원본) → wrapper(호출)</strong> 3중 구조입니다. times번 시도해 성공하면 즉시 반환, 지정 예외가 나면 남은 횟수만큼 재시도, 모두 실패하면 마지막 예외를 그대로 다시 발생시킵니다.</p></td>

3\. functools

3.1 @lru_cache — 결과 캐싱

from functools import lru_cache

@lru_cache(maxsize=1024)

def lookup(ip):

print(f"계산: {ip}") \# 본문은 실제 실행될 때만

return f"geo({ip})"

lookup("10.0.0.5") \# miss → 본문 실행 후 저장

lookup("10.0.0.5") \# hit → 본문 건너뛰고 저장값 반환

3.2 partial — 인자 부분 고정

from functools import partial

def tag(level, msg): return f"\[{level}\] {msg}"

warn = partial(tag, "WARN") \# 위치 인자 → 왼쪽부터 고정(level)

print(warn("disk 부족")) \# \[WARN\] disk 부족

def connect(host, port): return f"{host}:{port}"

local = partial(connect, port=8080) \# 키워드 인자 → 이름으로 고정

print(local("localhost")) \# localhost:8080

인자 일부를 미리 고정해 특화 함수를 만듭니다. 위치 인자는 왼쪽부터, 키워드 인자는 이름으로 고정합니다.

3.3 reduce — 하나의 값으로 누적

from functools import reduce

counts = \[3, 4, 2\]

combos = reduce(lambda a, b: a \* b, counts) \# 3\*4=12, 12\*2=24

print(combos) \# 24

\# 초기값을 주면 빈 시퀀스에도 TypeError 없이 안전

empty = reduce(lambda a, b: a \* b, \[\], 1) \# 1
