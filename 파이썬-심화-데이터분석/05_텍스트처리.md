1. 문자열 손기술

| **메서드** | **동작** | **예** |
|----|----|----|
| **strip()** | 양끝 공백·개행만 제거 (중간은 보존) | ' a b '.strip() → 'a b' |
| **split()** | 공백 기준 분할 (연속 공백은 한 구분자) | 'a b'.split() → ['a','b'] |
| **구분자.join(리스트)** | 조각 사이에 구분자 넣어 합침 | ','.join(['a','b']) → 'a,b' |
| **lower()** | 모든 대문자를 소문자로 (정규화) | 'ERROR'.lower() → 'error' |
| **startswith(s)** | 지정 접두사로 시작하면 True | '#c'.startswith('#') → True |

line = " Tom Anna Ed \n"

line.strip() \# 'Tom Anna Ed' (양끝만, 중간 공백 보존)

line.split() \# ['Tom','Anna','Ed']

",".join(["a","b","c"]) \# 'a,b,c' (join의 주어는 구분자!)

> **💡 헷갈리는 세 가지**
> **strip은 양끝만** — 중간 공백까지 없애려면 split이 필요합니다. **join의 주어는 리스트가 아니라 구분자**: names.join(",")가 아니라 ",".join(names).
> **lower()로 정규화:** 입력·로그를 비교·집계할 때 양쪽을 lower()로 맞추면 대소문자 무관 비교가 됩니다. startswith는 맨 앞만 검사하고, 중간 포함 판별은 'x' in line을 씁니다.

2. 인코딩 (Encoding)

인코딩은 글자를 컴퓨터가 저장할 **바이트**로 바꾸는 규칙입니다. 같은 글자도 인코딩에 따라 바이트 수가 다릅니다.

| **인코딩** | **한글 '가'** | **쓰이는 곳**                |
|------------|---------------|------------------------------|
| **utf-8**  | 3바이트       | 리눅스·맥·현대 시스템 (표준) |
| **cp949**  | 2바이트       | 구형 윈도우                  |

\# 열 때 encoding을 파일이 저장된 규칙과 맞춰야 함

with open(path, encoding="utf-8") as f:

text = f.read()

\# 인코딩이 안 맞으면 UnicodeDecodeError

\# 깨진 글자를 무시하고 끝까지 읽기:

open(path, encoding="utf-8", errors="replace") \# 깨진 자리를 로 대체

> **💡 utf-8 먼저, 깨지면 cp949**
> 저장 인코딩과 읽기 인코딩이 다르면 글자가 깨지거나 **UnicodeDecodeError**가 납니다. 새 파일·현대 시스템은 utf-8이 표준이니 **utf-8로 먼저 열고, 깨지면 cp949**로 다시 열어 확인하세요.
> **errors="replace":** 깨진 글자를 대체 문자로 바꾸고 나머지는 계속 읽습니다(기본 strict는 깨진 자리에서 중단). 원본 완전 복원은 올바른 인코딩으로 열어야만 됩니다.

3. 파일 입출력

**with open** 은 블록이 끝나면 파일을 자동으로 닫습니다(컨텍스트 매니저). 수동 close는 잊기 쉽고 예외 시 도달 못 할 수 있어요.

| **모드**           | **동작**                            |
|--------------------|-------------------------------------|
| **'r'** (읽기)     | 기본. 파일을 읽음                   |
| **'w'** (쓰기)     | 여는 즉시 기존 내용 삭제 후 새로 씀 |
| **'a'** (이어쓰기) | 끝에 이어 붙임 (로그 누적)          |

with open(path, "w", encoding="utf-8") as f:

f.write("Tom 90\n") \# write는 개행(\n)을 자동으로 안 붙임

f.write("Anna 85\n")

with open(path, encoding="utf-8") as f:

for line in f: \# 한 줄씩 순회 (큰 파일도 안전)

print(line.strip()) \# 끝의 \n 제거

읽기 메서드 4가지

| **방법**      | **읽는 양** | **결과**    | **추천**                    |
|---------------|-------------|-------------|-----------------------------|
| read()        | 전체        | 문자열 하나 | 작은 파일 전체              |
| readline()    | 한 줄       | 문자열 하나 | 첫 줄만                     |
| readlines()   | 전체        | 줄 리스트   | 작은 파일 줄 목록           |
| for line in f | 한 줄씩     | 반복 처리   | **기본 추천** (메모리 절약) |

> **💡 'w'는 덮어쓰기 — 누적은 'a'**
> **'w'는 여는 즉시 파일을 비웁니다.** 기존 내용을 지우지 않고 로그를 쌓으려면 **'a'(append)**를 쓰세요. write는 개행을 자동으로 붙이지 않으니 줄 끝에 \n을 직접 넣어야 합니다.

4. CSV — DictReader · DictWriter

**csv.DictReader** 는 첫 줄 헤더를 키로 각 행을 dict로 읽습니다. 열 이름으로 값을 꺼내 열 순서가 바뀌어도 안 깨집니다.

import csv

with open(path, encoding="utf-8") as f:

for r in csv.DictReader(f):

\# r = {"name":"Tom", "score":"90"} ← 값은 전부 문자열!

if int(r["score"]) >= 85: \# 숫자 비교 전 int() 변환

print(r["name"])

\# 쓰기: DictWriter

with open(out, "w", encoding="utf-8", newline="") as f:

w = csv.DictWriter(f, fieldnames=["name","score"])

w.writeheader() \# 헤더 행

w.writerow({"name":"Tom","score":"90"}) \# 한 건

w.writerows(rows) \# 여러 건(리스트)

> **💡 CSV 값은 전부 문자열 / newline=""**
> **DictReader가 읽은 값은 '90'도 int가 아닌 str**입니다. 숫자 비교·계산 전에 반드시 **int()**로 변환하세요(안 하면 문자열 비교라 틀림).
> **DictWriter의 fieldnames가 열 순서를 정합니다**(dict 순서 아님). 쓸 때는 **newline=""** 를 줘야 빈 줄이 끼지 않습니다.

5. JSON

API로 받은 JSON은 dict처럼 보여도 실제로는 **문자열(str)**입니다. 파싱해야 키·인덱스로 값을 꺼낼 수 있어요.

| **대상**         | **읽기 (→객체)** | **쓰기 (→내보내기)** |
|------------------|------------------|----------------------|
| **문자열 (str)** | json.loads(s)    | json.dumps(obj)      |
| **파일 (f)**     | json.load(f)     | json.dump(obj, f)    |

import json

raw = '{"name": "Tom", "scores": [90, 85]}' \# str

data = json.loads(raw) \# str → dict

data["name"] \# 'Tom'

data["scores"][0] \# 90 (키·인덱스를 이어 접근)

json.dumps({"별명":"꼬마"}) \# 한글이 \uXXXX로

json.dumps({"별명":"꼬마"}, ensure_ascii=False) \# 한글 그대로

> **💡 s는 string / ensure_ascii=False**
> **함수 이름 끝의 s는 string**을 뜻합니다: 문자열은 **loads·dumps**, 파일은 **load·dump**. 대상을 바꿔 호출하면 TypeError. JSON 키·문자열 값은 반드시 큰따옴표(작은따옴표면 에러).
> **dumps는 기본으로 한글을 \uXXXX로 이스케이프**합니다. 사람이 읽는 파일이면 **ensure_ascii=False**로 한글 원문을 그대로 남기세요.

6. 정규화와 집계

공백 개수·대소문자가 달라도 의미가 같으면 별개 항목으로 집계됩니다. 분석 전에 **형식을 통일(정규화)**해야 해요.

def normalize(s):

return " ".join(s.strip().split()).lower()

\# 중간공백 통일 양끝 대소문자

normalize(" Tom SCORED 90 ") \# 'tom scored 90'

\# 리스트에 일괄 적용

out = [normalize(l) for l in lines]

\# 이름별 카운트 — get(키, 0)+1

counts = {}

for name in names:

counts[name] = counts.get(name, 0) + 1 \# 처음 키도 KeyError 없이

> **💡 정규화 3단계 + get(k,0)+1**
> **normalize = strip(양끝) → split/join(중간 공백 하나로) → lower(소문자)**. 세 단계를 한 함수로 묶어 재사용합니다. 정규화 후 split()[0]로 첫 토큰(이름)을 뽑을 수 있는데, 빈 줄이면 [0]에서 IndexError라 **if not line.strip(): continue**로 빈 줄을 먼저 거릅니다.
> **counts.get(name, 0) + 1** 은 없는 키를 0으로 시작해 KeyError 없이 빈도를 셉니다(Counter로도 가능).
