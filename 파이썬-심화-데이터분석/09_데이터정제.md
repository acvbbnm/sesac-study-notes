목차

1. 정제 개요 · 왜 정제하나

수집 직후의 raw 표를 바로 분석하면 틀린 숫자가 나옵니다. **정제(cleaning)**는 결과를 신뢰할 수 있게 만드는 준비 단계로, **진단 → 처리 → 검증** 순서로 진행합니다.

- **raw 표** — 결측·중복·문자열 숫자 등 오류가 섞인 원본

- **정제** — 결측 처리·중복 제거·타입 변환·값 표준화

- **신뢰할 수 있는 표** — 이제 groupby·merge 등 분석 가능

> **💡 정제를 건너뛰면 조용히 틀린다**
> 정제를 생략하면 합계·평균·정렬·병합이 **에러 없이 '조용히 틀린 값'**을 냅니다. 문자열 "90"은 더해지지도 평균내지도 못하고, 중복 행은 평균을 왜곡합니다. 그래서 분석 전에 반드시 정제를 거쳐야 합니다.

2. 결측치(NaN) 개념

두 Series를 연산하면 위치가 아니라 **라벨을 기준으로 자동 정렬**한 뒤 같은 라벨끼리 계산합니다. 한쪽에만 있는 라벨은 짝이 없어 **NaN(Not a Number)**이 됩니다 — 이것도 결측치가 생기는 한 경우입니다.

import pandas as pd

s1 = pd.Series([90, 50], index=["월", "화"])

s2 = pd.Series([60, 20], index=["월", "수"])

print(s1 - s2) \# 라벨 기준 자동 정렬 후 연산

\# 월 30.0 (양쪽에 있음 → 90-60)

\# 화 NaN (s2에 '화' 없음 → 결측)

\# 수 NaN (s1에 '수' 없음 → 결측)

> **💡 NaN은 float · 위치가 아니라 라벨로 정렬**
> 판다스 연산은 순서(위치)가 아니라 **라벨(index)**을 맞춰 계산합니다. 짝이 없는 라벨은 NaN이 되고, NaN이 하나라도 섞이면 그 열의 dtype은 **float64**가 됩니다. 결측은 이렇게 연산에서도 생기고, 원본에 비어 있던 칸에서도 생깁니다.

3. 결측치 진단 · 삭제 (isna · dropna)

정제를 시작하기 전에 **어느 열이 얼마나 비었는지 진단**합니다. isna()는 각 원소가 NaN인지 True/False로 돌려주고, sum()으로 열별 결측 개수를 셉니다.

import pandas as pd, numpy as np

df = pd.DataFrame({"name":["kim","lee","park", np.nan,"choi"],

"city":["서울", np.nan,"부산","대구", np.nan],

"score":[90., 85., np.nan, 70., np.nan]})

df.isna().sum() \# 열별 결측 개수 → name 1, city 2, score 2

df.dropna() \# NaN이 하나라도 있는 행 전부 삭제

df.dropna(subset=["name"]) \# name이 결측인 행만 삭제(나머지 유지)

> **💡 먼저 진단, 그다음 subset으로 필수 열만**
> **df.isna().sum()** 으로 어느 열이 비었는지 먼저 파악합니다. **dropna()** 는 결측이 하나라도 있으면 행 전체를 지우므로 과하게 삭제될 수 있습니다. **dropna(subset=["name"])** 처럼 식별자 같은 **필수 열만** 기준으로 삭제하고, city·score의 결측은 뒤에서 fillna로 채우는 게 안전합니다.

4. 중복 제거 (duplicated · drop_duplicates)

duplicated()는 인자 없이 호출하면 **모든 열이 앞선 행과 완전히 같을 때 True**를 반환합니다(최초 등장은 False). sum()을 붙이면 중복 행의 총 개수를 셉니다.

df = pd.DataFrame({"name":["kim","lee","kim","park","lee"],

"city":["서울","부산","서울","대구","부산"],

"score":[90, 85, 90, 70, 85]})

df.duplicated() \# [False, False, True, False, True]

df.duplicated().sum() \# 2 (중복 행 개수)

df.drop_duplicates() \# 중복 행 제거(첫 등장만 남김)

df.drop_duplicates(subset=["name"]) \# name이 같으면 중복으로 간주

> **💡 duplicated는 표시만, drop_duplicates가 삭제**
> **duplicated()** 는 앞에 동일 행이 이미 있으면 True로 표시만 하고 원본은 그대로 둡니다(진단용). 실제 삭제는 **drop_duplicates()** 입니다. **subset=[...]** 을 주면 지정한 열만 같아도 중복으로 보고, keep="last"로 마지막 것을 남길 수도 있습니다.

5. 타입 변환 (astype · to_numeric)

숫자처럼 보여도 문자열(object)로 저장돼 있으면 계산이 안 됩니다. 모든 원소가 깨끗한 숫자 모양이면 **astype(int)** 과 **pd.to_numeric()** 둘 다 됩니다.

s = pd.Series(["403", "200", "500"]) \# 숫자처럼 보이는 문자열

s.astype(int) \# [403, 200, 500] 깨끗하면 OK

pd.to_numeric(s) \# [403, 200, 500] 결과 동일

하지만 변환 불가능한 값('N/A' 등)이 섞이면 **astype은 에러**를 냅니다. 이때 **to_numeric(errors="coerce")** 를 쓰면 실패한 값만 NaN으로 두고 나머지는 숫자로 바꿉니다.

s = pd.Series(["532", "N/A", "980"]) \# N/A 섞임

pd.to_numeric(s, errors="coerce")

\# [532.0, NaN, 980.0] 변환 실패한 'N/A'만 NaN, 전체는 float64

\# 날짜도 같은 패턴

pd.to_datetime(col, errors="coerce") \# 못 읽는 날짜는 NaT

> **💡 깨끗하면 astype, 지저분하면 coerce**
> 모든 값이 깨끗한 숫자면 **astype(int)**, 변환 불가 값이 섞였으면 **to_numeric(errors="coerce")**로 실패값을 NaN 처리합니다. coerce로 NaN이 생기면 열 전체가 float64가 되고, 남은 NaN은 fillna로 채웁니다. 날짜는 **to_datetime(errors="coerce")**로 같은 방식(실패는 NaT)입니다.

6. 값 치환 (replace)

replace에 딕셔너리를 주면 **키=바꿀 값, 값=새 값**으로 치환합니다. HTTP 상태 코드처럼 숫자를 사람이 읽을 문자열로 바꿀 때 유용합니다.

df = pd.DataFrame({"status": [200, 404, 301, 500]})

df["status"] = df["status"].replace({

200: "SUCCESS",

404: "NOT_FOUND",

500: "SERVER_ERROR",

})

\# ['SUCCESS', 'NOT_FOUND', 301, 'SERVER_ERROR']

\# 매핑에 없는 301은 그대로 유지 · dtype: int64 → object

> **💡 매핑에 없는 값은 그대로 · 재대입 필수**
> **replace(dict)**는 딕셔너리에 있는 값만 바꾸고, **매핑에 없는 값(301)은 그대로 둡니다**. 결과를 **df["status"] = ...** 로 다시 대입해야 원본에 반영됩니다. 숫자를 문자열로 바꾸면 열 dtype이 int64에서 object로 자동 변경됩니다.

7. 문자열 처리 (.str 접근자)

문자열 메서드는 원래 스칼라 값 하나에만 동작합니다. DataFrame 열에 **.str 접근자**를 붙이면 그 열의 **모든 행에 문자열 메서드를 일괄 적용**합니다(for 루프 불필요).

df = pd.DataFrame({"store": ["서울 강남", "부산 해운대", "서울 종로"]})

df["store"].str.contains("서울") \# [True, False, True] 포함 여부

한 셀에 여러 정보가 공백으로 뭉쳐 있으면 **str.split()**으로 나눈 뒤 **.str[0], .str[1]** 인덱스로 조각별 열을 추출합니다.

df = pd.DataFrame({"info": ["홍길동 서울 90", "김유신 부산 85", "이순신 서울 70"]})

df["name"] = df["info"].str.split().str[0] \# 홍길동 · 김유신 · 이순신

df["city"] = df["info"].str.split().str[1] \# 서울 · 부산 · 서울

df["score"] = pd.to_numeric(df["info"].str.split().str[2]) \# 90 · 85 · 70

> **💡 .str로 열 전체 일괄 처리**
> **.str 접근자**는 열의 모든 원소에 문자열 메서드를 한 번에 적용합니다(contains·split·strip·lower 등). **split()**으로 공백 기준 리스트로 나눈 뒤 **.str[i]**로 조각을 뽑고, 숫자로 쓸 조각은 **to_numeric**으로 마무리 변환합니다.

8. 정돈 (rename · reset_index)

rename은 columns 매개변수에 **{옛이름: 새이름}** 딕셔너리를 줘 헤더 이름을 바꿉니다. 공백·대문자 헤더를 snake_case로 통일할 때 씁니다. **반환값을 다시 df에 대입**해야 원본이 갱신됩니다.

df = df.rename(columns={"Source IP":"src_ip",

"Status":"status",

"Time Stamp":"ts"})

\# columns → ['src_ip', 'status', 'ts']

정렬 등으로 뒤섞인 인덱스는 **reset_index(drop=True)**로 0부터 다시 매깁니다. drop을 생략하면 기존 인덱스가 'index' 열로 추가됩니다.

df = df.sort_values("bytes", ascending=False) \# 정렬로 인덱스가 꼬임

clean = df.reset_index(drop=True) \# 0,1,2... 새로 매김

df.reset_index() \# drop 생략 → 기존 인덱스가 'index' 열로 남음

> **💡 rename·reset_index 모두 재대입 필요**
> **rename(columns={...})**과 **reset_index(drop=True)**는 새 DataFrame을 반환하므로 df에 다시 대입해야 반영됩니다. 헤더는 snake_case로 통일하고, 정렬 후 꼬인 번호는 reset_index로 0부터 정돈해 다음 분석의 깔끔한 입력을 만듭니다.

9. 시간순 결측 채우기 (ffill)

시간순으로 정렬된 데이터에서 결측치는 흔히 **직전 시점의 값**을 따릅니다(센서 로그 등). pandas의 **ffill()**은 바로 위 행의 값으로 결측을 채워(forward fill) 이전 값을 전파합니다.

df = pd.DataFrame({"ts":[10, 20, 30], "bytes":[100.0, None, 300.0]})

correct = df.sort_values("ts").ffill() \# 시간순 정렬 후 ffill (옳음)

\# [100.0, 100.0, 300.0] 직전 100을 전파

wrong = df.sort_values("bytes").ffill().sort_values("ts") \# 크기순 정렬 후 (틀림)

\# [100.0, 300.0, 300.0] 엉뚱한 값이 채워짐

> **💡 ffill 전에 반드시 시간순 정렬**
> **ffill()**은 '바로 위 행'의 값으로 채우므로, **어떤 순서로 정렬돼 있느냐에 따라 채워지는 값이 달라집니다**. 반드시 **sort_values(시간열)**로 시간순 정렬을 먼저 하고 ffill해야 시간상 직전 값이 들어갑니다. 크기순 등 다른 기준으로 정렬한 뒤 ffill하면 값이 오염됩니다.

10. 처리 순서 (통합 워크플로우)

정제는 순서가 중요합니다. 작은 더러운 표를 분석 가능한 tidy 표로 만드는 표준 흐름:

| **단계** | **작업** | **도구** |
|----|----|----|
| ① 타입 교정 | 문자열 숫자를 수치·날짜로 | **to_numeric / to_datetime** (coerce) |
| ② 중복 제거 | 완전히 같은 중복 행 삭제 | **drop_duplicates()** |
| ③ 결측 채움 | 남은 NaN을 대푯값/직전값으로 | **fillna(중앙값) / ffill()** |
| ④ 표기 표준화 | 값·헤더를 통일 | **replace(dict) / rename** |
| ⑤ 정돈 | 정렬·인덱스 초기화 | **sort_values / reset_index** |

> **💡 순서를 지켜야 중앙값이 왜곡되지 않는다**
> 특히 **중복을 먼저 제거한 뒤 결측을 채워야** 합니다. 중복이 남은 채로 중앙값을 계산하면 대푯값이 왜곡되기 때문입니다. 순서는 **타입 교정 → 중복 제거 → 결측 채움**이 기본이며, ffill은 분석용 정렬보다 먼저(시간순으로) 수행해야 직전 값이 올바로 들어갑니다.

> **💡 Ch09 핵심 3**
> ① 결측과 중복은 열 특성에 따라 처리 — 필수 열 결측은 **dropna(subset)**, 나머지는 **fillna·ffill**, 중복은 **drop_duplicates**. ② 타입을 교정해야 계산·날짜 비교 가능 — **to_numeric·to_datetime의 coerce**. ③ 헤더는 **rename**으로 통일하고 인덱스는 **reset_index(drop=True)**로 0부터 다시 맞춘다.
