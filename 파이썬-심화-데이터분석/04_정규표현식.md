re 기본 · 문자클래스 · 메타문자·반복 · 검증 · 치환

목차

1\. re 기본 — search · findall · group

정규식의 핵심은 **검색·수집·추출** 세 동작입니다. 패턴 앞에는 항상 **r** 접두사를 붙여 원시 문자열로 쓰세요.

import re

m = re.search(r"\d", "hello 7") \# \d = 숫자 한 개, 왼쪽부터 첫 매치

print(m.group()) \# 7

nums = re.findall(r"\d+", "a1 b22 c3") \# 전부 → \["1","22","3"\]

no = re.findall(r"\d+", "abc") \# 없으면 \[\]

m = re.search(r"점수 (\d+)", "코드 A12 점수 90")

m.group() \# "점수 90" (매치 전체)

m.group(1) \# "90" (소괄호로 캡처한 부분)

| **함수** | **동작** | **못 찾으면** |
|----|----|----|
| **search** | 첫 일치 하나 | **None** 반환 |
| **findall** | 모든 일치를 리스트로 | **빈 리스트 \[\]** |
| **group()** | Match에서 일치 문자열 꺼내기 | (group은 re 함수 아니라 Match의 메서드) |

<p><strong>r"..."</strong> 는 파이썬이 백슬래시를 먼저 해석하지 않게 해 <strong>\d·\w·\b</strong> 같은 메타문자를 정규식 엔진에 그대로 전달합니다. 없으면 \n·\t 등이 의도와 다르게 해석돼요 — 항상 r 붙이기.</p>

2\. 문자 클래스 약어 \d \w \s

특정 문자가 아니라 그 **종류에 속하는 문자 한 개**를 매칭합니다.

| **약어** | **뜻 (문자 한 개)**           | **반대 (대문자)**     |
|----------|-------------------------------|-----------------------|
| **\d**   | 숫자                          | **\D** (숫자 아닌 것) |
| **\w**   | 글자·숫자·밑줄 (영문·한글 등) | **\W**                |
| **\s**   | 공백 (스페이스·탭·줄바꿈)     | **\S**                |

re.findall(r"\d", "Tom 90") \# \["9","0"\] 한 글자씩

re.findall(r"\d+", "Tom 90") \# \["90"\] 연속 덩어리

re.findall(r"\w+", "Tom 90") \# \["Tom","90"\] 공백에서 끊김

<colgroup>
<col style="width: 100%" />
</colgroup>
<tbody>

<td><p><strong>💡 + 하나 차이 / 파이썬은 유니코드 기본</strong></p>
<p><strong>\d</strong> 는 한 글자씩, <strong>\d+</strong> 는 같은 종류가 <strong>연속된 구간을 하나로</strong> 묶어 반환합니다. 대문자 \D·\W·\S는 각각의 반대 집합이에요.</p>
<p>파이썬 정규식은 유니코드 기본이라 <strong>\w에 한글도 포함</strong>되고, \s에 탭·줄바꼈이 포함됩니다.</p></td>
</tr>

3\. 메타문자와 반복

메타문자는 글자 그대로가 아니라 **검색 규칙**으로 해석되는 기호입니다.

| **기호**   | **의미**                    | **예**                             |
|------------|-----------------------------|------------------------------------|
| **.**      | 줄바꿈 제외 임의의 한 글자  | a.c → abc·a3c·a c (가운데 한 자리) |
| \*\*\*\*\* | 바로 앞 요소 0회 이상       | ab\* → a·ab·abb                    |
| **+**      | 바로 앞 요소 1회 이상       | ab+ → ab·abb (a는 탈락)            |
| **?**      | 바로 앞 요소 0회 또는 1회   | https? → http·https                |
| **\|**     | 왼·오른쪽 패턴 중 하나 (OR) | cat\|dog → cat 또는 dog            |
| **\\**     | 이스케이프 → 실제 점 문자   | \d+\\\d+ → 1.5·12.75               |

<table>
<colgroup>
<col style="width: 100%" />
</colgroup>
<tbody>
<tr>
<td><p><strong>💡 * vs + vs ? / 이스케이프</strong></p>
<p><strong>*는 0회도 허용</strong>해서 앞 요소가 없어도 매치되고, <strong>+는 최소 1회를 요구</strong>합니다. ?는 있어도/없어도 OK. 이 수량자는 문자뿐 아니라 \d·(ab) 같은 바로 앞 요소 전체에 적용돼요.</p>
<p><strong>.</strong> 같은 메타문자를 글자 그대로 찾으려면 앞에 백슬래시를 붙여 이스케이프합니다: <strong>\.</strong> 는 임의 문자가 아니라 실제 점에만 일치.</p></td>
</tr>
</tbody>

4\. 정확한 횟수 {n} {n,} {n,m}

| **패턴**  | **의미**             | **예**                           |
|-----------|----------------------|----------------------------------|
| **{n}**   | 정확히 n회           | \d{3} → 403 (3자리). 12·7은 탈락 |
| **{n,}**  | n회 이상 (상한 없음) | \d{4,} → 44228                   |
| **{n,m}** | n회 이상 m회 이하    | \d{1,3} → 7·42·100               |

5\. 문자 클래스 \[abc\] · \[a-z\]

대괄호 **\[...\]** 안에 나열한 문자 중 **하나**에 일치하는 문자 클래스를 만듭니다.

re.findall(r"\[aeiou\]", "banana") \# \["a","a","a"\] 모음만

re.findall(r"\[0-9\]", "a1 b2") \# \["1","2"\] 숫자 = \d

re.findall(r"\[a-z0-9\]", "a1!b2") \# \["a","1","b","2"\] 범위 결합

| **클래스**    | **의미**            |
|---------------|---------------------|
| \[abc\]       | a·b·c 중 한 문자    |
| \[a-z\]       | 소문자 한 글자      |
| \[0-9\]       | 숫자 한 글자 (= \d) |
| \[a-zA-Z0-9\] | 영문·숫자 한 글자   |

<p>대괄호 안 하이픈은 <strong>시작·끝 문자의 범위</strong>를 지정합니다([a-z]=소문자). 범위·문자를 여러 개 이어 붙일 수도 있어요: <strong>[a-z0-9]</strong> = 소문자 또는 숫자 (특수문자는 제외).</p></td>

6\. 검증 — match · search · fullmatch

| **함수**      | **물음**        | **설명**                               |
|---------------|-----------------|----------------------------------------|
| **match**     | 앞에서 맞나?    | **문자열 시작 위치**에서만 일치 확인   |
| **search**    | 어딘가에 있나?  | 위치 무관하게 전체 탐색 (첫 일치)      |
| **fullmatch** | 전체가 다 맞나? | **문자열 전체**가 패턴과 일치해야 True |

re.match(r"\d", "id 42") \# None ("i"가 숫자 아님 → 시작 실패)

re.search(r"\d", "id 42") \# "4" (전체 탐색 → 첫 숫자)

\# 입력 검증엔 fullmatch — 일부만 맞아도 통과시키면 위험

pattern = r"\[a-z0-9\]+"

bool(re.search(pattern, "bad!")) \# True ← "bad"만 걸려 통과 (위험)

bool(re.fullmatch(pattern, "bad!")) \# False ← "!" 때문에 전체 차단 (안전)

bool(re.fullmatch(pattern, "nick12")) \# True (전체가 소문자+숫자)

<td><p><strong>💡 입력 검증에는 search 말고 fullmatch</strong></p>
<p><strong>search는 '어딘가에 있나?'</strong>만 보므로 허용 문자 밖의 글자('!')가 섞여 있어도 일부만 맞으면 통과시켜 위험합니다. <strong>fullmatch는 '전체가 다 맞나?'</strong>를 보므로 이메일·아이디 같은 입력 형식 검증에 안전합니다.</p></td>

7\. 치환·플래그 — re.sub · re.I

\# re.sub(패턴, 바꿀값, 텍스트) → 원본은 안 바뀌고 새 문자열을 반환

re.sub(r"\d", "\*", "ip 10.0.0.5") \# "ip \*\*.\*.\*.\*" (숫자 가리기)

\# re.I(IGNORECASE) 플래그 → 대소문자 무시

len(re.findall(r"fail", "FAIL fail Fail", re.I)) \# 3

예고 — 이름붙은 그룹

\# 번호 그룹: 여러 개면 group(1)·group(2)가 뭐였는지 되짚어야 함

m = re.search(r"(\d+)월 (\d+)점", text)

m.group(1) \# 월, m.group(2) \# 점

\# 이름붙은 그룹: (?P\<이름\>패턴) → 이름으로 참조해 한눈에

m = re.search(r"(?P\<month\>\d+)월 (?P\<score\>\d+)점", text)

m.group("month"); m.group("score")

그룹이 많을수록 번호보다 **이름(?P\<이름\>...)**이 가독성이 좋습니다. lookaround·역참조는 중급 실습에서 다룹니다.
