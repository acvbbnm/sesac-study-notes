1\. 컴프리헨션 (Comprehension)

for + append 반복 패턴을 **단일 표현식**으로 작성하는 문법. 대괄호 \[ \]는 리스트, 중괄호 { }는 dict·set을 만듭니다.

out = \[n \* 2 for n in nums\] \# 리스트: \[변환 for 원소 in 반복가능\]

out = \[x \* 2 for x in xs if x \> 0\] \# 뒤 if = 필터 (조건 참인 것만)

front = \["ok" if c \< 400 else "x" for c in codes\] \# 앞 if-else = 변환

squares = {n: n\*\*2 for n in nums} \# dict 컴프리헨션

uniq = {x for x in xs} \# set 컴프리헨션

1.1 if 위치 — 필터 vs 변환

| **위치** | **형태** | **동작** |
|----|----|----|
| **뒤 if** | \[c for c in xs **if** c\<400\] | **필터**: 조건 참인 원소만 남김 → 개수 감소. else 없음 |
| **앞 if-else** | \["ok" **if** c\<400 **else** "x" for c in xs\] | **변환**: 모든 원소를 값으로 바꿈 → 개수 유지. else 필수 |

2\. 이터레이터 (Iterator)

**iterable** = for로 값을 하나씩 꺼낼 수 있는 객체(list·tuple·dict·set·str·range). **iterator** = iter()로 얻으며 next()로 값을 꺼내고 '어디까지 꺼냈는지' 위치를 기억하는 객체.

2.1 for의 내부 3단계

\# for x in xs: print(x) ← 아래 3단계의 줄임말

it = iter(xs) \# ① iterator 생성

print(next(it)) \# ② next로 값을 하나씩 꺼냄

try:

print(next(it))

except StopIteration: \# ③ 값이 없으면 StopIteration → for는 멈춤

pass

|             | **iterable (list 등)** | **iterator**         |
|-------------|------------------------|----------------------|
| for 순회    | 가능                   | 가능                 |
| next() 직접 | **불가 (TypeError)**   | **가능** (위치 기억) |
| 예          | xs = \[1,2,3\]         | it = iter(xs)        |

2.2 일회성 함정

g = map(int, \["1","2","3"\])

print(list(g)) \# \[1, 2, 3\] ← 첫 순회가 다 소비

print(list(g)) \# \[\] ← 둘째는 텅 빔

3\. 제너레이터 (Generator)

**yield** 를 쓰는 함수. 호출하면 본문을 실행하지 않고 제너레이터 객체만 만들며, next() 때마다 **yield까지 실행하고 멈췄다가 다음 next에 그 다음 줄부터 재개**합니다.

def gen():

print("start")

yield 1

yield 2

g = gen() \# 객체만 생성 (본문 미실행)

print(next(g)) \# "start" 출력 → yield 1에서 정지, 1 반환

print(next(g)) \# 멈춘 다음 줄부터 재개 → 2 반환

print(next(g)) \# 더 없음 → StopIteration

3.1 제너레이터 표현식 — 소괄호

sq_list = \[x\*x for x in xs\] \# 대괄호 → 리스트 (전부 메모리에)

total = sum(x\*x for x in xs) \# 소괄호 → 제너레이터 (중간 리스트 없이 합산)

4\. 로그 스트리밍 (지연 평가 활용)

대용량 로그를 다룰 때 제너레이터로 **한 줄씩 흘려보내면** 메모리를 아낄 수 있습니다.

whole = list(raw) \# readlines: 전부 한꺼번에 메모리로 (수 GB → OOM 위험)

def read_lines(rows): \# 제너레이터: 한 줄씩 흘림

for line in rows:

yield line.rstrip()

\# 파일 객체 자체가 iterator → 헬퍼 없이 직접

with open("access.log") as f:

for line in f: \# 한 줄씩, 전체를 메모리에 적재하지 않음

...

4.1 지연 파이프라인 (Lazy)

def only_failed(lines):

for line in lines:

if "Failed password" in line:

yield line

pipe = only_failed(read_lines(raw)) \# 연결만 함 → 아직 0줄도 안 읽음!

count = sum(1 for \_ in pipe) \# 소비자(sum)가 순회를 시작해야 실행

5\. 함수형 도구 — map · filter · sorted

| **도구** | **동작** | **반환** |
|----|----|----|
| **map(f, xs)** | 각 원소에 f를 1:1 적용 | **iterator** (list()로 변환) |
| **filter(f, xs)** | f가 참을 반환하는 원소만 남김 | iterator, 개수 감소 |
| **sorted(xs, key=)** | key 함수가 뽑은 기준값으로 정렬 | **새 리스트** |

nums = list(map(int, \["80","443"\])) \# \[80, 443\]

big = list(filter(lambda p: p \> 1023, nums)) \# 조건 참만

\# sorted(key=)로 기준값 추출 정렬

top = sorted(hits, key=lambda kv: kv\[1\], reverse=True) \# 튜플 2번째 값 기준 내림차순

<colgroup>
<col style="width: 100%" />
</colgroup>
<tbody>

<td><p><strong>💡 lambda의 두 역할 / sorted vs sort</strong></p>
<p><strong>filter의 lambda는 True/False(조건)</strong>, <strong>sorted의 key=lambda는 정렬 기준값을 추출</strong>합니다. 같은 lambda라도 쓰임이 다릅니다.</p>
<p><strong>sorted(xs)</strong> 는 새 리스트를 반환(원본 유지), <strong>xs.sort()</strong> 는 원본을 제자리 정렬하고 <strong>None을 반환</strong>합니다. x = xs.sort() 처럼 결과를 변수에 담으면 None이 되니 주의.</p></td>

6\. itertools

iterable을 연결·분할·그룹화·조합하는 함수 모음. 반환값은 모두 iterator입니다.

6.1 chain · islice

from itertools import chain, islice

all_ips = chain(srv1, srv2) \# 복사 없이 이어붙임

first3 = islice(chain(srv1,srv2), 3) \# 앞 3개만 자름 (\[:3\]은 iterator에 불가)

6.2 groupby — 인접한 같은 키만 묶음

from itertools import groupby

rows.sort(key=lambda r: r\[0\]) \# ★ 정렬을 먼저 해야 온전한 그룹

for k, g in groupby(rows, key=lambda r: r\[0\]):

print(k, \[x for x in g\])

7\. 언패킹 (Unpacking)

7.1 확장 언패킹 — 별표 분배

a, \*rest, b = \[1, 2, 3, 4, 5\]

\# a=1, rest=\[2,3,4\], b=5 (별표 변수는 한 줄에 하나만, 나머지를 리스트로)

7.2 받기(packing) vs 풀기(unpacking)

\# 받기: 여러 인자를 한 변수로 (함수 정의)

def f(\*args, \*\*kwargs): \# \*args → 튜플, \*\*kwargs → dict

...

f(1, 2, a=3, b=4) \# args=(1,2), kwargs={"a":3,"b":4}

\# 풀기: 하나를 여러 개로 (함수 호출)

args = (1, 2); kw = {"a":3, "b":4}

g(\*args, \*\*kw) \# g(1, 2, a=3, b=4) 와 동일

8\. collections 모듈

| **도구** | **용도** | **핵심** |
|----|----|----|
| **deque(maxlen=N)** | 최근 N개만 유지 | 꽉 찬 뒤 추가하면 반대편이 자동 제거 (rolling window) |
| **Counter** | 빈도 집계 | Counter(xs), .most_common(k)로 상위 k개 |
| **defaultdict(list)** | 없는 키 자동 기본값 | 키 확인 없이 바로 append (그룹화 편함) |
| **namedtuple** | 이름으로 접근하는 튜플 | e.ip·e.port 처럼 필드 이름으로 접근 |

from collections import deque, Counter, defaultdict, namedtuple

w = deque(\[1,2,3\], maxlen=3); w.append(4) \# deque(\[2,3,4\]) — 왼쪽 1 밀려남

cnt = Counter(ips); cnt.most_common(2) \# 상위 2개 \[(ip,3), ...\]

by_ip = defaultdict(list)

for ip, status in logs:

by_ip\[ip\].append(status) \# 키 검사 없이 바로 누적

Entry = namedtuple("Entry", \["ip","user","port"\])

e = Entry("10.0.0.5","root",22); print(e.ip, e.port)

9\. 핵심 정리 & 퀴즈

| **주제** | **핵심 한 줄** |
|----|----|
| **컴프리헨션** | 뒤 if=필터, 앞 if-else=변환(else 필수). 이중 for로 평탄화 |
| **이터레이터** | iterable은 for만, iterator는 next+위치기억. map/filter는 일회성 |
| **제너레이터** | yield로 멈췄다 재개. 소괄호 표현식은 지연 평가로 메모리 절약 |
| **함수형 도구** | map(1:1)·filter(선별)·sorted(key=). sorted는 새 리스트, sort는 None |
| **itertools** | chain·islice / groupby(정렬 먼저!) / product·comb·perm |
| **언패킹** | a,\*rest,b / \*·\*\*로 받기(packing)·풀기(unpacking) / zip은 짧은 쪽 |
| **collections** | deque·Counter·defaultdict·namedtuple |
