# 새벽항로 실습 시작 안내

이 자료는 공개 사고의 행위 유형을 참고한 **합성 로그 조사 실습**입니다. 실제 회사의 유출 데이터나 실제 침해 로그가 아닙니다. 이전 수업 자료·AWS 계정·API 키·유료 서비스 없이 진행합니다.

## 파일 열기

1. `시나리오2_학생배포.zip`을 PC에 내려받아 압축을 풉니다.
2. 브라우저에서 [Google Colab](https://colab.research.google.com/)에 로그인합니다.
3. **파일 → 노트북 업로드**에서 `01_새벽항로_사건조사.ipynb`를 선택합니다.
4. **파일 → Drive에 사본 저장**으로 개인 답안 사본을 만듭니다.
5. **연결**을 누르고 왼쪽 파일 창에 `새벽항로_evidence.zip`을 업로드합니다. 증거 ZIP은 풀지 않습니다.
6. 이름을 바꾸는 첫 셀, 데이터 준비 셀 순서로 ▶ 또는 Shift+Enter를 누릅니다. `증거 ZIP 확인 완료 / 사건: HC-2026-0715`가 표시되면 준비되었습니다.

노트북 업로드와 증거 ZIP 업로드는 별개입니다. Drive 연결 코드는 필요하지 않습니다. 새 런타임에서는 ZIP을 다시 업로드합니다. 기존 노트북은 Colab으로 가져올 수 있습니다. [Colab 공식 안내](https://research.google.com/colaboratory/faq.html)

로컬에서는 노트북과 증거 ZIP을 같은 폴더에 둡니다. Python 3.10 이상에 Jupyter, pandas 2.2 이상, IPython이 필요합니다. 준비된 로컬 환경이 없다면 수업에서는 Colab을 사용합니다. 설치를 선택한 경우 배포된 `requirements.txt`를 별도 가상환경에서 설치한 뒤 `jupyter notebook`으로 엽니다.

## 진행 방식

- 설명을 먼저 읽고 예상·가설을 적습니다. 코드 셀을 실행한 뒤 표에서 근거 ID를 확인합니다.
- H1~H4는 함수의 TODO를 직접 작성합니다. `raise NotImplementedError(...)`를 지우고 구현한 뒤 **함수 정의 → 검증** 셀을 다시 실행합니다.
- 검증 셀의 작은 예시는 룰의 요구 조건입니다. 실제 사건의 사용자·키·IP를 고정해 답을 맞추지 않습니다.
- H1 결과에서 `FOCUS_REQUEST`, H2 결과에서 `FOCUS_KEY`를 선택해 입력합니다. 값을 바꿨다면 이후 조사 셀도 다시 실행합니다.
- 초기 조사 뒤 강사의 안내에 따라 `FOLLOWUP_RELEASED = True`로 바꿉니다. 추가 자료는 학습 단계만 구분한 것이며 암호화되어 있지 않습니다.
- 단순 전체 실행은 심화 함수를 완성하지 않습니다. 미완료 상태가 보이는 것은 정상입니다.

## 막혔을 때

| 상황 | 확인할 것 |
|---|---|
| 코드와 중괄호만 보임 | 텍스트 편집기 대신 Colab에서 ipynb를 업로드했는지 확인 |
| FileNotFoundError | 증거 ZIP 이름과 업로드 완료 여부 확인 |
| 무결성 확인 실패 | 배포된 증거 ZIP을 다시 받아 사용; 기존 ZIP을 직접 수정하지 않기 |
| 미완료 문구 | TODO 함수를 구현하고 정의 셀부터 다시 실행 |
| AssertionError | 검증 셀을 고치지 말고 메시지의 조건·중복·경계값 점검 |
| 이전 결과가 그대로임 | 수정한 함수 또는 입력 셀을 재실행했는지 확인 |
| NameError | 준비 셀부터 실행했는지, 런타임이 초기화되었는지 확인 |
| 조회 결과 0행 | 곧바로 실패로 간주하지 말고 UTC/KST, 공백, 키, 시각 범위 점검 |

## 제출

룰 4개, 검증 출력, 직접 추가한 분석 코드, 근거 ID, 초기·최종 영향 비교, 타임라인과 보고서를 남깁니다. 개인 사본을 저장하고 **파일 → 다운로드 → .ipynb 다운로드**로 `HC_2026_0715_이름.ipynb`를 제출합니다. 증거 ZIP을 답안에 다시 첨부할 필요는 없습니다.

## 검토판 재실행 안내

키 또는 요청 ID를 바꾸면 기존 결과를 비웁니다. H2 검증→키 선택→H3 검증→추가 자료 공개→H4 검증→영향 비교 순서로 다시 실행합니다. 함수를 수정했다면 정의 셀과 검증 셀을 모두 실행합니다. 마지막 완료 표시는 현재 선택에서 실제 분석이 끝났는지도 확인합니다. 존재하지 않는 ID나 추가 자료 미공개는 다음 행동 안내로 표시되며 이전 답을 재사용하지 않습니다.


## 로컬 환경 준비 명령

학생 ZIP을 푼 폴더에서 PowerShell을 엽니다. 설치는 수업 전에 수행하며 인터넷이 필요합니다. 준비된 환경에서 노트북 분석은 오프라인으로 가능합니다.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m notebook
```

열린 파일 목록에서 `01_새벽항로_사건조사.ipynb`를 선택합니다. 증거 ZIP은 노트북과 같은 폴더에 둡니다. `py`가 없다면 강사의 준비 환경이나 설치된 Python 경로를 사용합니다. 설명 셀을 더블클릭하면 답안을 적을 수 있고 Shift+Enter로 표시합니다. 코드를 수정하면 정의 셀과 검증 셀을 다시 실행해야 새 결과가 나옵니다.
