# 시나리오1 시작 안내

Python 경험과 AWS 기본 개념이 있는 위협헌팅 입문자를 위한 약 5시간 실습입니다. AWS 계정·인증 정보는 필요하지 않습니다. 데이터는 교육용 합성 자료이며 실제 환경에 명령을 실행하지 않습니다.

## 처음 노트북 열기

1. **시나리오1_학생배포.zip**을 내려받아 Windows 탐색기에서 우클릭 → 모두 압축 풀기를 선택합니다. ZIP 안에서 바로 편집하지 않습니다.
2. 브라우저에서 [Google Colab](https://colab.research.google.com/)에 로그인합니다.
3. **파일 → 노트북 업로드**에서 `01_CloudTrail_헌팅.ipynb`를 선택합니다. ipynb는 코드와 설명·출력을 한 문서에서 다루는 파일입니다. 메모장으로 열면 JSON 글자가 보입니다.
4. **파일 → Drive에 사본 저장** 후 이름을 `시나리오1_이름.ipynb`로 바꿉니다.
5. **연결**을 누른 뒤 왼쪽 파일 창에 `cloudtrail_raw_events.csv`, `logs_aggregated_user_hour.csv` 두 개를 올립니다. 노트북 업로드와 데이터 업로드는 별도입니다. Drive 마운트는 필요하지 않습니다.
6. 첫 설명을 읽고 다음 준비 코드 셀의 ▶ 또는 **Shift+Enter**를 누릅니다. `이벤트 129,805행 / 집계 8,065행 / 분석 주체 39개`가 나오면 준비되었습니다.
7. 설명 셀은 더블클릭해 가설·예상을 적고 Shift+Enter로 표시합니다. 코드 셀은 수정하고 다시 실행해야 변경이 반영됩니다. 실행 번호는 셀 위치가 아니라 실행 순서입니다.

교안 요약 사건을 먼저 진행하면 `02_장표사례_분석.ipynb`를 같은 방법으로 열고 JSON 두 개를 파일 창에 올립니다. 이 노트북에서는 CSV가 필요하지 않습니다. 다시 메인 노트북으로 돌아가면 해당 런타임에 CSV가 있는지 확인합니다.

## 로컬 Jupyter로 열기

로컬을 선택하면 Python 3.10 이상과 패키지를 수업 전에 준비합니다. 노트북·CSV·JSON·requirements.txt를 같은 폴더에 두고 그 폴더에서 PowerShell을 엽니다. 설치에는 인터넷이 필요하며 준비된 환경의 분석 실행은 오프라인으로 가능합니다.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m notebook
```

브라우저에 열린 Jupyter 파일 목록에서 `.ipynb`를 선택합니다. `py`를 찾을 수 없으면 사전 설치된 Python 경로를 사용하거나 강사의 준비 환경을 사용합니다. 이 명령은 가상환경의 실행 파일을 직접 사용하므로 PowerShell 활성화 스크립트는 필요하지 않습니다.

## 진행과 저장

- 설명 → 예상 작성 → 코드 실행 → 표 해석 순서로 진행합니다. 기본 M1~M6, 연결 B1~B2, 심화 A1~A4가 있습니다.
- A1~A4는 `raise NotImplementedError(...)`를 지우고 조건·집계·결합 코드를 직접 씁니다. 함수 정의 셀과 바로 다음 검증 셀을 차례로 실행합니다. 검증 셀의 정답 조건을 바꾸지 않습니다.
- 전체 실행만 하면 4개 심화가 미완료로 남는 것이 정상입니다. 코드 통과와 보고서 완성은 별도입니다.
- 함수 정의를 다시 실행하면 해당 통과 상태가 초기화됩니다. 입력·임계값을 바꾸면 해당 셀부터 아래 셀까지 다시 실행합니다. 혼란스러우면 개인 답안을 저장한 뒤 런타임/커널 재시작 후 처음부터 실행합니다.
- Colab 런타임을 새로 연결하면 CSV·JSON을 다시 올립니다. PC에 받은 원본 CSV를 수정하지 않습니다.
- 제출 시 **파일 → 다운로드 → .ipynb 다운로드**로 개인 답안을 저장합니다. 별도 보고서는 `04_보고서양식.md`를 복사해 작성해도 됩니다.

## 막혔을 때

| 화면·오류 | 다음 행동 |
|---|---|
| FileNotFoundError | 이름이 정확한 CSV 두 개 또는 JSON 두 개가 해당 런타임의 파일 창에 있는지 확인 |
| ModuleNotFoundError | 로컬은 requirements 설치에 쓴 Python으로 Jupyter를 열었는지 확인 |
| NameError | 준비 셀 또는 앞 단계 변수 정의 셀부터 순서대로 실행 |
| AssertionError | 경계값·분모·그룹 키·반환 열을 메시지에 맞게 점검 |
| A1~A4 미완료 | TODO 구현 후 함수 정의와 검증 셀 모두 실행 |
| 결과가 0행 | UTC/KST와 날짜·시간창·공백·필터 범위를 확인; 0행도 유효한 결과일 수 있음 |
| 낮은 모델 점수 | 공격 확률이 아님; 낮을수록 모델이 상대적으로 드물다고 본 후보 |
| 키·정책·MFA 정보가 없음 | 현재 자료의 미확인 사항으로 보고하고 필요한 추가 자료를 제안; 필수 분석은 계속 진행 |

## 파일 구분

`01_CloudTrail_헌팅.ipynb`와 두 CSV는 3주 자료입니다. `02_장표사례_분석.ipynb`의 `장표127_요약사건.json`은 교안에서 전사한 별개 요약 사건입니다. `필터연습_가상입력.json`은 별도의 조건 연습 예시입니다. 세 자료를 합쳐 한 침해사고처럼 해석하지 않습니다.
