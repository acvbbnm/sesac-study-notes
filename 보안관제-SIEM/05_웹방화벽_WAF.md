# 05. 웹방화벽 (WAF) 이해

---

## 1. 개요

웹 기반 서비스가 발전하면서 항상 개방되어 있는 웹(포트 80/443)을 통한 공격이 일반화·집중화됨. 단순 홈페이지 변조부터 웹서버를 통한 악성코드 유포까지 사고 발생.

**WAF (Web Application Firewall)**는 웹서버 앞 단에 위치하여 외부에서 들어오는 HTTP/HTTPS 프로토콜 트래픽을 감시하고, 웹 어플리케이션에 대한 악의적인 공격을 웹서버 도달 전에 차단하는 전용 보안 시스템.

> 방화벽은 80/443 포트 자체를 열어두어야 하므로 해당 포트를 통한 웹 공격은 차단 불가 → WAF로 보완

---

## 2. 구성

```
[인터넷]
    │
[라우터]
    │
[방화벽]  ← Port 23 Close / Port 80 Open
    │
[웹방화벽]  ← HTTP/HTTPS 트래픽 분석·차단
    │
[웹서버]
```

---

## 3. 주요 기능

### 탐지 로그

- 정의한 탐지 룰에 따라 탐지된 이벤트 목록 제공
- 제공 정보: 탐지 룰, 위험 행동 대상의 주소·국가, 대상 URL, 발생 시각
- **Raw Data 상세보기**: 탐지 이벤트에서 우클릭 → 상세보기 → Raw data 확인 후 Decoding
- 정탐/오탐 유무 판단 → 대응

### 감사 로그

- 운영 관련 감사 정보를 목록 형태로 제공
- 데이터 종류: 로그인 관련 / 설정 변경 / 시스템 / 데이터 / 네트워크 인터페이스

### 정책 설정

- 탐지 보안 정책 및 웹서버 정보 설정
- 정책 변경 시 **저장 버튼 클릭** 필수 (취소 클릭 시 저장 안 됨)
- 신규 웹서버 추가: 설정 마법사 → 네트워크 설정 → 웹서버 IP/Port/Mode 설정
- **SSL 기능**: 웹서버 설정에서 SSL 항목 선택 시 인증서(cert) + 키(key) 파일 등록 필요
- **Proxy IP 설정**: Proxy 모드 시 필요. Inline 모드 시 불필요

---

## 4. WAF 동작 모드

| 모드 | 설명 |
|------|------|
| **Inline 모드** | 웹방화벽이 직접 트래픽을 처리. 차단 가능 |
| **Proxy 모드** | 웹방화벽이 프록시 역할. Proxy IP 별도 설정 필요 |

---

## 5. WAF vs 방화벽 비교

| 항목 | 방화벽 | WAF |
|------|--------|-----|
| 분석 계층 | L3/L4 (IP, Port) | L7 (HTTP 헤더, 본문, URL, 파라미터) |
| 차단 기준 | IP·포트 기반 ACL | 웹 공격 패턴 (SQL Injection, XSS 등) |
| HTTP 80/443 | 열어두어야 함 | 해당 포트 내 악성 요청 탐지·차단 |
