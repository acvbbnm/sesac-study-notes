# 10. 네트워크 구성도 샘플

---

## 기본 3계층 웹서비스 구성

```
            [L3 Router]
                 │
               [L4]
           (Load Balancer)
                 │
            [BB (L2)]
           백본 스위치
      ┌─────────┼─────────┐
   [was#1]  [was#2,#3]  [was#4]
    WAS 서버   WAS 서버   WAS 서버
```

### 각 계층 역할

| 계층 | 장비 | 역할 |
|------|------|------|
| **L3 Router** | 라우터 | 외부 인터넷과 내부 망 간 라우팅 |
| **L4** | 로드밸런서 | 트래픽을 여러 WAS 서버로 분산 (세션 기반) |
| **BB (L2)** | 백본 스위치 | 내부 서버 간 고속 스위칭 |
| **WAS 서버** | 웹 애플리케이션 서버 | 비즈니스 로직 처리 |

### 보안 장비 적용 예시

```
[인터넷]
    │
[L3 Router]
    │
[방화벽]       ← 외부 → 내부 접근 제어 (ACL)
    │
[IPS]          ← 알려진 공격 패턴 실시간 차단 (In-line)
    │
[WAF]          ← HTTP/HTTPS 웹 공격 차단 (SQL Injection, XSS 등)
    │
[L4 LB]        ← 로드밸런싱
    │
[BB L2]
    │
[WAS #1~4]
    │
[DB 서버]      ← DB 방화벽(DBF), DB 접근 제어
```

### 미러링(IDS) 추가 구성

```
[스위치]
    │─────────────────────→ [IDS]
    │    (포트 미러링)     탐지 전용 (차단 불가)
   서버군
```

## DMZ 구간 포함 구성

```
[인터넷]
    │
[라우터]
    │
[방화벽]
  ├── [DMZ 구간]
  │    └── 웹서버, 메일서버, DNS 등 (외부 접근 가능)
  └── [내부망]
       ├── WAS 서버
       └── DB 서버 (외부 직접 접근 불가)
```

**Zone 간 통신 정책 원칙**
- 외부 → DMZ: 허용된 서비스 포트만 오픈 (80, 443 등)
- DMZ → 내부망: 최소 권한 원칙 적용 (필요한 포트만 허용)
- 외부 → 내부망: **기본 차단** (Any Deny)
- 내부망 → 외부: 정책에 따라 허용 or 프록시 경유
