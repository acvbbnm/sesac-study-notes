# 03. Astaro UTM 설치 실습

출처: 로컬 `4일차 실습 자료/UTM 설치 Software/소프트웨어 UTM장비 설치 가이드.pdf`, 20쪽.

## 1. 목적과 환경 (p.2-4)

VMware에 Astaro UTM을 설치하고 관리 PC에서 WebAdmin 대시보드에 접속하는 실습이다. 교안의 설치 이미지는 `latest_asg_v8_software`이고 해당 ISO가 로컬 배포 폴더에 존재한다.

VM 생성 과정에서 설치 ISO, 가상 디스크와 네트워크 어댑터를 구성한다. 교안 화면은 관리·외부 연결용 어댑터를 구분한다. 실습 VM의 실제 인터페이스 매핑을 확인해 관리망이 의도한 VMnet에 연결되도록 한다.

## 2. OS 설치 (p.5-11)

1. 생성한 UTM VM을 시작해 설치 프로그램을 진행한다.
2. 시간대를 Asia → Seoul로 선택한다.
3. 관리 인터페이스로 eth0을 선택한다.
4. 관리 IP를 `192.168.56.254`, 마스크를 `255.255.255.0`으로 설정한다.
5. 설치와 재시작을 마친 뒤 콘솔 화면을 확인한다.

교안 p.11에는 구형 환경의 초기 콘솔 계정 설정 화면이 있다. 이를 현재 시스템의 인증 상태로 가정하지 않는다. 실제 비밀번호는 학습 기록에 넣지 않는다.

## 3. 관리 PC 설정 (p.12-14)

| 항목 | 교안 값 |
|---|---|
| 관리 PC | Windows XP VM |
| 연결 | VMnet1(Host-only) |
| IP | 192.168.56.120 |
| 마스크 | 255.255.255.0 |
| 게이트웨이 | 192.168.56.254 |

UTM의 관리 인터페이스도 같은 관리망에 연결되어 있어야 한다. 관리 PC에서 게이트웨이 주소로 ping을 보내 연결을 확인한다.

## 4. WebAdmin 초기 설정 (p.15-19)

1. 관리 PC 브라우저에서 `https://192.168.56.254:4444`에 접속한다.
2. 초기 등록 항목과 관리 비밀번호를 설정한다.
3. 재시작 후 등록한 계정으로 로그인한다.
4. 교안은 초기 마법사를 Cancel로 중단하고 대시보드를 확인하는 지점까지 진행한다.

접속 실패 시 VMnet·관리 IP·인터페이스·관리 포트를 확인한다. 관리 화면 접속 성공과 외부 인터넷 연결·방화벽 정책 적용 성공은 별개의 검증이다.

## 5. 실습 결과 기록 범위

이 가이드가 설명하는 완료 지점은 UTM OS 설치와 관리 대시보드 접속이다. IPS·VPN·웹 필터 정책 적용까지 수행했다고 확대하지 않는다. 사용자 환경의 설치 완료 화면이나 접속 결과는 이번 작업에서 확인하지 않았다.
