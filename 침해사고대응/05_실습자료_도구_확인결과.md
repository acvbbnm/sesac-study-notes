## 4. MFT와 타임라인 자료

`DATA/MFT.csv`를 CSV 형식으로 읽어 헤더를 제외한 **357,100개 행**, `SourceFile` 값 1종을 확인했다. 주요 필드는 다음과 같다.

| 필드 | 분석 용도 |
|---|---|
| EntryNumber, SequenceNumber | MFT 레코드 식별 |
| ParentPath, FileName, Extension | 경로·파일 후보 찾기 |
| InUse, IsDirectory | 레코드 상태·디렉터리 구분 |
| Created0x10 / Created0x30 | SI/FN 속성의 생성 시각 비교 |
| LastModified*, LastRecordChange*, LastAccess* | 서로 다른 시간 의미 비교 |
| HasAds, IsAds, ZoneIdContents | ADS 관련 항목 조사 |
| SourceFile | 원본 추적 |

행 수는 고유 파일 수와 같다고 단정하지 않는다. 타임스탬프 차이만으로 조작을 확정하지 않고 파일 복사·이동·시스템 동작과 다른 로그를 비교한다.

`Prefetch Tracking.ctr`는 분석 프로젝트로 보이는 파일이 존재한다는 수준까지 확인했다. 내부 내용을 열어 결과를 검증하지 않았으므로 완료된 타임라인으로 기록하지 않는다.

## 5. 도구 구성

KAPE와 gkape, MFTECmd, TimelineExplorer, PECmd, AmcacheParser, EvtxECmd, RECmd, LECmd, JLECmd 실행 파일과 RegRipper 자료가 있다. NTFS Log Tracker 폴더와 WinHex 배포 압축파일도 있다. 도구 설명서·라이선스 MD는 수업 정리 문서와 구분한다.

분석 흐름은 원본 보존 → 필요한 파서로 별도 결과 생성 → TimelineExplorer 등으로 필터 → 다른 아티팩트와 교차 확인 → 타임라인·결론 작성이다. 도구의 존재는 설치·정상 실행·분석 성공과 별개다.

## 6. 기타 배포 사례

- `RANSOMWARE CASE.zip`: ZIP 내부 항목 572개(디렉터리 포함), Amcache와 이벤트 로그 등 확인. 랜섬웨어 조사용 입력 자료로 분류하며 감염 시점·종류·피해 범위는 미확정이다.
- `DATA/DFC2019 - IR300.7z`: 사례 압축파일 존재 확인. 내부 내용을 해제·분석하지 않았으므로 문제 풀이를 추정하지 않는다.
- `ARTIFACT.7z`: 배포 압축파일. 현재 `ARTIFACT/`와 동일한 내용인지 무결성 대조하지 않았다.

## 7. 결과 보고 시 남길 항목
