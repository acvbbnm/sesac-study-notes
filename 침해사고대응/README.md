페이지 번호는 PDF의 첫 페이지를 1로 센 번호다. 설명은 교안을 요약하고 실습 이해를 위한 해석을 덧붙였다. 교안에 인용된 제품 버전·통계는 해당 교안 기준이며 최신 제품 안내가 아니다.

**교안 실습**은 수업에서 제시한 과제, **자료 확인**은 현재 폴더에서 확인한 파일, **완료 확인**은 실행 로그·결과로 입증되는 범위를 뜻한다. 배포 자료가 있다는 이유로 사용자가 모든 실습을 직접 완료했다고 기록하지 않았다. 문서 작성 중 도구·배치 파일·악성코드는 실행하지 않았다.

원본 PDF, 수집 데이터, 분석 도구와 VM 이미지는 로컬 자료다. Git에는 이 정리 문서와 목차를 게시한다. 로컬 경로는 원본을 찾기 위한 설명이며 GitHub에서 다운로드할 수 있다는 의미가 아니다.
