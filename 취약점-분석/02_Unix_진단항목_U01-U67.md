# 02. Unix(Linux) 진단 항목 (U-01 ~ U-67)

## 1. 계정 관리 (U-01 ~ U-13)

| 코드 | 점검항목 | 중요도 | 핵심 점검 내용 |
|------|---------|:---:|------|
| U-01 | root 계정 원격 접속 제한 | 상 | SSH `PermitRootLogin No`, Telnet 지양 |
| U-02 | 비밀번호 관리정책 설정 | 상 | `/etc/pam.d/system-auth` 영문+숫자+특수문자 8자 이상 |
| U-03 | 계정 잠금 임계값 설정 | 상 | 임계값 10회, 잠금 60분(3600초) |
| U-04 | 비밀번호 파일 보호 | 상 | shadow 파일 존재, passwd 계정 암호화 확인 |
| U-05 | root 이외의 UID 0 금지 | 상 | UID 0은 root만 유일 |
| U-06 | 사용자 계정 su 기능 제한 | 상 | wheel 그룹 허용 사용자만 su 가능 |
| U-07 | 불필요한 계정 제거 | 하 | 퇴직·휴직 계정 즉시 회수 |
| U-08 | 관리자 그룹에 최소한의 계정 포함 | 중 | `/etc/login.defs` 최대 사용기간 90일 이하 |
| U-09 | 계정이 존재하지 않는 GID 금지 | 하 | 불필요 그룹 제거 |
| U-10 | 동일한 UID 금지 | 중 | UID 중복 시 권한·감사 추적 문제 |
| U-11 | 사용자 Shell 점검 | 하 | 로그인 불필요 계정에 `/bin/false`, `/sbin/nologin` |
| U-12 | 세션 종료 시간 설정 | 하 | Session timeout 설정 (유휴 접근 차단) |
| U-13 | 안전한 비밀번호 암호화 알고리즘 사용 | 중 | SHA-512 등 강력한 해시 사용 |

**U-01 상세 (조치 방법)**
```bash
# LINUX - SSH
# /etc/ssh/sshd_config
PermitRootLogin No

# LINUX - Telnet
# /etc/securetty 에서 pts/x 주석 처리 및 제거
#pts/0
#pts/1
# /etc/pam.d/login 에 모듈 추가
auth required /lib/security/pam_securetty.so
```
> CentOS 8, Ubuntu 20.04 이상은 `/etc/securetty`가 없고 Telnet이 기본 비활성화.

## 2. 파일 및 디렉터리 관리 (U-14 ~ U-33)

| 코드 | 점검항목 | 중요도 | 핵심 내용 |
|------|---------|:---:|------|
| U-14 | root 홈, 패스 디렉터리 권한 및 패스 설정 | 상 | PATH 환경변수 맨 앞·중간 `.` 포함 여부 |
| U-15 | 파일 및 디렉터리 소유자 설정 | 상 | 소유자 없는 파일·디렉터리 제거 |
| U-16 | /etc/passwd 파일 소유자 및 권한 | 상 | root 소유, 644 이하 |
| U-17 | 시스템 시작 스크립트 권한 설정 | 상 | 관리자만 제어 가능 |
| U-18 | /etc/shadow 파일 소유자 및 권한 | 상 | root 소유, 400 |
| U-19 | /etc/hosts 파일 소유자 및 권한 | 상 | 파밍(Pharming) 방지, 644 이하 |
| U-20 | /etc/(x)inetd.conf 파일 소유자 및 권한 | 상 | root 소유, 600 |
| U-21 | /etc/(r)syslog.conf 파일 소유자 및 권한 | 상 | root 소유, 640 이하 |
| U-22 | /etc/services 파일 소유자 및 권한 | 상 | root 소유, 644 이하 |
| U-23 | SUID, SGID, Sticky bit 설정 파일 점검 | 상 | 불필요한 SUID/SGID 제거 (root 권한 상승 방지) |
| U-24 | 사용자·시스템 환경변수 파일 소유자 및 권한 | 상 | 환경변수 파일 변조 방지 |
| U-25 | world writable 파일 점검 | 상 | 누구나 쓰기 가능한 파일 제거 |
| U-26 | /dev에 존재하지 않는 device 파일 점검 | 상 | rootkit 위장 파일 탐지 |
| U-27 | $HOME/.rhosts, hosts.equiv 사용 금지 | 상 | r-command 원격 실행 차단 |
| U-28 | 접속 IP 및 포트 제한 | 상 | TCP Wrapper (hosts.allow/deny) |
| U-29 | hosts.lpd 파일 소유자 및 권한 | 하 | 삭제 또는 권한 관리 |
| U-30 | UMASK 설정 관리 | 중 | UMASK 022 이상 |
| U-31 | 홈 디렉터리 소유자 및 권한 설정 | 중 | 소유자 외 쓰기 권한 제거 |
| U-32 | 홈 디렉터리로 지정한 디렉터리의 존재 관리 | 중 | 존재하지 않는 홈 디렉터리 점검 |
| U-33 | 숨겨진 파일 및 디렉터리 검색 및 제거 | 하 | 악성 은닉 파일·백도어 탐지 |
