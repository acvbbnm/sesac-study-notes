# 06. 환경분석 실전 예시 (CentOS 6.9)

> 실제 진단 대상 서버의 환경분석 완료 결과. 포트·데몬·계정 분석 후 총평까지의 실전 작성 예시.  
> ([01. SYSTEM 환경분석](./01_SYSTEM_환경분석.md)의 방법을 실제 서버에 적용한 결과)

---

## 1. 대상 기본정보

| 항목 | 값 | 진단 관점 |
|------|------|----------|
| **OS** | CentOS 6.9 | ⚠️ **EOS(2020.11 지원 종료)** — 신규 취약점 패치 불가 |
| **DBMS** | MySQL 5.1.73-8 | ⚠️ 구버전 (5.1은 EOL). 알려진 취약점 다수 |
| **Web Server** | Apache 2.2.15-69 | ⚠️ 2.2 계열 EOL(2017 종료) |
| **WAS** | N/A | 별도 WAS 미사용 |

> 기본정보만으로도 OS·DB·WEB 모두 지원 종료(EOS/EOL) 상태 → **패치 관리(U-64) 즉시 취약** 판정 대상.

## 2. 포트 분석

| Proto | Local Address | Well-Known | Program | 서비스 | 진단 관점 |
|------|--------------|:---:|--------|--------|----------|
| tcp | 0.0.0.0:22 | Y | sshd | SSH | 🟢 정상. root 직접접속 차단 확인 필요(U-01) |
| tcp | 0.0.0.0:3306 | Y | mysqld | MySQL | ⚠️ **DB가 외부(0.0.0.0) 노출** → 로컬/내부망 바인딩 권장 |
| tcp | 0.0.0.0:111 | Y | rpcbind | RPC 포트매퍼 | ⚠️ 불필요 시 중지(U-42) |
| tcp | 0.0.0.0:39939 | N | rpc.statd | NFS 상태 모니터 | ⚠️ 랜덤 고포트 RPC 서비스. NFS 미사용 시 중지(U-39) |
| tcp | 127.0.0.1:631 | Y | cupsd | 프린터(IPP) | 로컬 한정(🟢). 서버에 불필요하면 중지 |
| tcp | 127.0.0.1:25 | Y | master | Postfix SMTP | 로컬 한정(🟢). 릴레이 제한 확인(U-47) |
| tcp | :::80 | Y | httpd | Apache HTTP | 웹 서비스. IPv6(::) 리슨 |

### 포트 분석 소견
- **외부 노출 위험**: `3306(MySQL)`, `111/39939(RPC)`이 `0.0.0.0`으로 외부 접근 가능 → 접근제어·바인딩 조정 필요
- **RPC 계열**: rpcbind + rpc.statd는 버퍼오버플로우·DoS 취약점 이력이 많음. NFS를 쓰지 않으면 둘 다 중지 (U-39, U-42)
- **불필요 서비스**: 프린터(cupsd)는 서버 환경에 보통 불필요

## 3. 데몬 분석 (요약)

전체 80여 개 프로세스 중 **보안 관점 주요 데몬**만 발췌:

| RUSER | Command | 목적 | 진단 관점 |
|-------|---------|------|----------|
| root | sshd | SSH 서비스 | 필수. 설정 점검(U-01) |
| mysql | mysqld | DB 구동 | mysql 계정으로 실행(🟢 권한 분리) |
| root | mysqld_safe | MySQL 안전 구동 래퍼 | 정상 (PPID로 mysqld의 부모) |
| apache | httpd | 웹 서버 | apache 계정 실행(🟢) |
| rpc | rpcbind | RPC 포트매퍼 | ⚠️ 미사용 시 중지 |
| rpcuser | rpc.statd | NFS 상태 모니터 | ⚠️ 미사용 시 중지 |
| root | cupsd | 프린터 | ⚠️ 서버에 불필요 |
| root | master(+qmgr/pickup) | Postfix 메일 | 릴레이 설정 점검 |
| root | crond / at | 작업 스케줄러 | crontab 권한 점검(U-37) |

### ⚠️ 핵심 소견: GUI(GNOME) 환경 다수 구동

데몬 목록에 `Xorg`, `gdm-binary`, `metacity`, `nautilus`, `gnome-*`, `ibus-*`, `pulseaudio`, `bluetooth-applet` 등 **데스크톱 GUI 관련 프로세스가 대량** 확인됨.

- **서버에는 GUI가 불필요** — 공격 표면 확대, 리소스 낭비, 불필요 서비스(U-18/W-18 관점)
- 조치: 서버 운영 시 GUI 패키지 제거 또는 `runlevel 3`(텍스트 모드)로 전환
  ```bash
  # CentOS 6: /etc/inittab 에서
  id:3:initdefault:      # 5(GUI) → 3(텍스트)
  ```
- 블루투스(`bluetooth-applet`), 무선랜(`wpa_supplicant`), 모뎀(`modem-manager`) 등 서버에 불필요한 장치 서비스도 다수 구동 중 → 중지 검토

## 4. 계정 분석 (요약)

`/etc/passwd` 총 37개 계정. **로그인 가능(`/bin/bash`) 계정**만 발췌:

| Username | UID(추정) | Shell | 비고 | 진단 관점 |
|----------|:---:|------|------|----------|
| root | 0 | /bin/bash | 최고관리자 | UID 0 유일 확인(U-05) |
| adiosl | 500+ | /bin/bash | 일반 사용자 | 정상 |
| cubrid | 500+ | /bin/bash | 일반 사용자 | 사용 여부 확인 (미사용 시 제거 U-07) |
| **mysql** | <500 | **/bin/bash** | MySQL 서비스 | ⚠️ **서비스 계정에 로그인 셸 부여** → `/sbin/nologin` 권장(U-11) |

### 계정 분석 소견
- **시스템 계정 셸 점검(U-11)**: `mysql`은 서비스 계정인데 `/bin/bash` 부여됨 → 로그인 불가 셸(`/sbin/nologin`)로 변경 권장
- **불필요 계정(U-07)**: `sync`, `shutdown`, `halt`, `games`, `gopher`, `uucp` 등 기본 계정 중 미사용분 검토
- **양호 사항**: 대부분의 시스템 계정(bin, daemon, apache, sshd 등)은 `/sbin/nologin`으로 로그인 차단됨(🟢)

## 5. 환경분석 총평

| 구분 | 발견 사항 | 위험도 |
|------|----------|:---:|
| **기본 정보** | CentOS 6.9 / MySQL 5.1 / Apache 2.2 — 모두 **EOS/EOL** | 🔴 상 |
| **Port 정보** | MySQL(3306)·RPC(111/39939) **외부 노출** | 🔴 상 |
| **Daemon 정보** | 서버에 불필요한 **GUI(GNOME) 및 장치 서비스 대량 구동** | 🟠 중 |
| **계정 정보** | 서비스 계정(mysql)에 **로그인 셸 부여**, 미사용 기본 계정 존재 | 🟠 중 |

### 우선 조치 권고 (중요도 순)
1. **[상] EOS OS·SW 대응**: CentOS 7+ 이상으로 마이그레이션 또는 격리·보완 통제 수립
2. **[상] 외부 노출 서비스 차단**: MySQL은 내부망/로컬 바인딩, RPC는 미사용 시 중지 (U-39, U-42)
3. **[중] 불필요 서비스 제거**: GUI(GNOME), 블루투스, 무선랜, 프린터(cupsd) 등 중지 (U-18)
4. **[중] 서비스 계정 셸 제한**: mysql 계정을 `/sbin/nologin`으로 변경 (U-11)
5. **[중] 불필요 계정 정리**: 미사용 기본 계정 제거 (U-07)

> 이 총평을 기준으로 U-01~U-67 항목별 상세 진단(→ [02. Unix 진단 항목](./02_Unix_진단항목_U01-U67.md))을 진행하고, 결과보고서(→ [05](./05_결과보고서_작성_가이드.md))에 항목별 [현황]+[대응방안]을 기술한다.
